CMDB + RELATIONSHIP MAP

老闆最想看的升級：CMDB 從資產表變成關聯影響圖

這份 before / after 只聚焦 CMDB 與關聯圖。升級重點不是多做一張表， 而是讓主管能立刻知道資料準不準、缺什麼、哪個系統關聯哪些主機、誰負責、出事要通知誰。

資料品質：正式 / 草稿 / 缺 owner / 錯誤
關聯覆蓋：系統 / 主機 / 服務 / 通知
影響判斷：選系統就看受影響範圍
治理閉環：匯入、修正、正式化、回饋

待補清單

  • 補齊 2 筆 owner / 保管者。
  • 確認 4 筆草稿資產是否轉正式。
  • 補齊服務 / Port 關聯，讓影響圖可用於事件判斷。
  • 匯出錯誤摘要，回饋原資料維護窗口修正。

這個升級實際要做的功能

CMDB 資料品質儀表板 正式、草稿、錯誤、缺 owner、缺通知、缺 Port 一頁看清楚。
關聯覆蓋率 統計資產是否已關聯系統、主機、服務、owner、PAM 與通知對象。
核心系統關聯圖 選一個核心系統，直接看到服務、主機、IP、負責人與通知群組。
待補與回饋流程 把缺欄位、匯入錯誤、草稿資料整理成可匯出的修正清單。

Backup Q&A

主管可能關心的事項與建議回答

建議作為備詢附件，不在主簡報一開始主動展開。主簡報聚焦案例、效益與導入方向； 若主管追問，再用本附件補充治理、成本、權限與維運方式。

後續維護量會不會增加？

會需要安排維護窗口，但平台可把原本分散在多份檔案、Script 與人工經驗中的工作集中管理，讓維護內容更可追蹤。

AI 判讀如何使用比較穩妥？

AI 不直接取代採證與決策。Shell、API、CMDB 與 NMON 先提供證據，AI 協助摘要與分級，重要操作仍保留人工確認。

如果 AI 或 API Key 暫時不可用怎麼辦？

系統設計保留 Script fallback。L1 基礎檢查可以不依賴 AI，L2/L3 再依情境使用模型與預算。

成本如何掌握？

建議採 L1/L2/L3 分級，低複雜度情境用 Script 或低成本模型，深度判讀才使用高階模型，並設定月預算與降級策略。

資料品質如何逐步補齊？

導入時可同步建立欄位規則與資料窗口。平台協助呈現可補強項目，讓各單位逐步對齊資料內容。

權限與資料保護怎麼安排？

以最小權限設計角色，區分讀取、匯出、巡檢、管理與 API Key 設定；文件與畫面不顯示真實 key。

建議主動講的只有一句：平台會以「可追溯證據 + 人工確認 + 成本分級」方式導入，AI 先作為維運判讀輔助。

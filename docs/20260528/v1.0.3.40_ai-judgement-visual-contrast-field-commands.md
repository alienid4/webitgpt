# v1.0.3.40 AI 判斷來源視覺強化現場指令

這版修正「只看到一排 badge，看不出差異」的問題。AI 判讀會是金框卡，Script 是灰框，資料/規則是綠框，fallback 是琥珀框。

## 安裝

```bash
cd /tmp
curl -LO https://github.com/alienid4/webitgpt/releases/download/v1.0.3.40/webitgpt_v1.0.3.40-patch-ai-judgement-visual-contrast_20260528000500.tar.gz
curl -LO https://github.com/alienid4/webitgpt/releases/download/v1.0.3.40/webitgpt_v1.0.3.40-patch-ai-judgement-visual-contrast_20260528000500.tar.gz.sha256
sha256sum -c webitgpt_v1.0.3.40-patch-ai-judgement-visual-contrast_20260528000500.tar.gz.sha256
tar -xzf webitgpt_v1.0.3.40-patch-ai-judgement-visual-contrast_20260528000500.tar.gz
cd webitgpt_v1.0.3.40-patch-ai-judgement-visual-contrast_20260528000500
sudo bash INSTALL_PATCH.sh /opt/webitgpt
```

## 驗證

```bash
curl -fsS http://127.0.0.1:8002/health
curl -fsS http://127.0.0.1:8002/ready
systemctl is-active webitgpt
grep -R "judgement-source-card ai" -n /opt/webitgpt/webapp/templates | head -20
grep -n "judgement-source-card.ai" /opt/webitgpt/webapp/static/css/cathay.css
```

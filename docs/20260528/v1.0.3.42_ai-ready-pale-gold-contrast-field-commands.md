# v1.0.3.42 AI-ready 淡金框現場指令

這版把「AI-ready / 可交給 AI 判讀」改成淡金框，和真正 AI 判斷的深金框分開。

## 安裝

```bash
cd /tmp
curl -LO https://github.com/alienid4/webitgpt/releases/download/v1.0.3.42/webitgpt_v1.0.3.42-patch-ai-ready-pale-gold-contrast_20260528002500.tar.gz
curl -LO https://github.com/alienid4/webitgpt/releases/download/v1.0.3.42/webitgpt_v1.0.3.42-patch-ai-ready-pale-gold-contrast_20260528002500.tar.gz.sha256
sha256sum -c webitgpt_v1.0.3.42-patch-ai-ready-pale-gold-contrast_20260528002500.tar.gz.sha256
tar -xzf webitgpt_v1.0.3.42-patch-ai-ready-pale-gold-contrast_20260528002500.tar.gz
cd webitgpt_v1.0.3.42-patch-ai-ready-pale-gold-contrast_20260528002500
sudo bash INSTALL_PATCH.sh /opt/webitgpt
```

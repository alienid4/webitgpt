# v1.0.3.41 靜態檔快取刷新現場指令

這版修正「後端已更新，但畫面看起來沒變」的問題。CSS/JS 會帶版本參數，例如 `cathay.css?v=1.0.3.41-static-asset-cache-busting`，瀏覽器會自動抓新檔。

## 安裝

```bash
cd /tmp
curl -LO https://github.com/alienid4/webitgpt/releases/download/v1.0.3.41/webitgpt_v1.0.3.41-patch-static-asset-cache-busting_20260528001500.tar.gz
curl -LO https://github.com/alienid4/webitgpt/releases/download/v1.0.3.41/webitgpt_v1.0.3.41-patch-static-asset-cache-busting_20260528001500.tar.gz.sha256
sha256sum -c webitgpt_v1.0.3.41-patch-static-asset-cache-busting_20260528001500.tar.gz.sha256
tar -xzf webitgpt_v1.0.3.41-patch-static-asset-cache-busting_20260528001500.tar.gz
cd webitgpt_v1.0.3.41-patch-static-asset-cache-busting_20260528001500
sudo bash INSTALL_PATCH.sh /opt/webitgpt
```

## 驗證

```bash
curl -fsS http://127.0.0.1:8002/health
curl -fsS http://127.0.0.1:8002/ready
curl -fsS http://127.0.0.1:8002/accounts | grep "css/cathay.css.*static-asset-cache-busting"
curl -fsS http://127.0.0.1:8002/accounts | grep "judgement-source-card ai"
```

## 人眼檢查

開啟：

- `http://<host>:8002/accounts`
- `http://<host>:8002/superadmin/ai`
- `http://<host>:8002/superadmin/token-costs`

若仍看不到變化，先確認右上或 footer 版本是否為 `v1.0.3.41`。不是 `v1.0.3.41` 就代表你看的不是已更新主機。

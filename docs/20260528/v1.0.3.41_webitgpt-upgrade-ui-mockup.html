5. AI 判讀升級：全系統共通的金框語言

不只 L3，主機、帳號、效能、影響圖、匯入錯誤摘要都能清楚標示「可判讀」或「已判讀」。

升級功能：AI Judgement Layer

淡金框：AI-ready

資料已足夠，可交給 AI 產生摘要、風險描述或下一步建議，但尚未產出正式判讀。

深金框：AI 已判讀

AI 已根據 script 採證、CMDB、帳號與效能資料產出判讀，畫面會保留來源與 fallback 狀態。

1. Shell 採證 nmap、SSH、WinRM、NMON、health endpoint。
2. Rule 判斷 先用 script / rule 判斷明確正常或異常。
3. AI-ready 資料足夠但需要語意整理時，標成淡金框。
4. AI 判讀 依 API Key、預算階級、L1/L2/L3 決定是否送判讀。
5. Script fallback API 不可用或超預算時，保留現有 script 結果接手。

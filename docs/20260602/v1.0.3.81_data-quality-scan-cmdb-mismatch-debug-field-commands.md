# v1.0.3.81 data-quality-scan-cmdb-mismatch-debug field commands

用途：當畫面上看得到資產，但「資料品質」仍顯示「掃描到但 CMDB 無」時，用這份去敏化指令確認是資料真的缺漏，還是資料品質比對邏輯誤判。

注意：

- 這份輸出可提供給 AI 或外部協助者判讀，預設不印出真實 IP、Hostname、資產編號、系統代號或人名。
- 不要貼完整 Mongo 文件、journalctl、access log、error log 或未去敏化截圖。
- 請只回傳此指令輸出的 JSON 摘要。

## 去敏化診斷指令

在 webitgpt 主機執行：

```bash
cd /opt/webitgpt
PYTHONPATH=/opt/webitgpt ./venv/bin/python - <<'PY'
import hashlib, json
from collections import Counter, defaultdict

from webapp.config import VERSION, PATCH_ID
from webapp.services.cmdb_service import asset_quality_report
from webapp.services.mongo_service import get_collection

def h(value):
    text = str(value or "").strip()
    if not text or text == "-":
        return ""
    return hashlib.sha256(text.encode("utf-8", "ignore")).hexdigest()[:12]

def norm_ip(value):
    return str(value or "").strip()

cmdb = asset_quality_report()
issues = cmdb.get("issues") or []
scan_not = [i for i in issues if i.get("type") == "scan_not_in_cmdb"]

hosts = list(get_collection("hosts").find({}, {
    "_id": 0,
    "asset_seq": 1,
    "hostname": 1,
    "ip": 1,
    "ip_addresses": 1,
    "status": 1,
    "host_type": 1
}))

host_ip_rows = []
for doc in hosts:
    ips = []
    if doc.get("ip"):
        ips.append(norm_ip(doc.get("ip")))
    raw_ips = doc.get("ip_addresses")
    if isinstance(raw_ips, list):
        ips.extend(norm_ip(x) for x in raw_ips)
    elif isinstance(raw_ips, str):
        ips.extend(norm_ip(x) for x in raw_ips.replace(";", ",").split(","))
    for ip in {x for x in ips if x}:
        host_ip_rows.append({
            "ip_hash": h(ip),
            "status": doc.get("status") or "",
            "host_type": doc.get("host_type") or "",
            "host_hash": h(doc.get("hostname")),
            "asset_hash": h(doc.get("asset_seq"))
        })

ip_statuses = defaultdict(Counter)
for row in host_ip_rows:
    ip_statuses[row["ip_hash"]][row["status"]] += 1

scan_ip_hashes = [h(i.get("ip")) for i in scan_not if i.get("ip")]
host_ip_hashes = {row["ip_hash"] for row in host_ip_rows}
formal_statuses = {"active", "using", "in_use"}
formal_ip_hashes = {row["ip_hash"] for row in host_ip_rows if row["status"] in formal_statuses}
draft_ip_hashes = {row["ip_hash"] for row in host_ip_rows if row["status"] == "draft"}

samples = []
for item in scan_not[:20]:
    ip_hash = h(item.get("ip"))
    samples.append({
        "issue_type": item.get("type"),
        "ip_hash": ip_hash,
        "issue_status": item.get("status") or "",
        "matched_host_status_counts": dict(ip_statuses.get(ip_hash, {}))
    })

dups = {
    ip_hash: count
    for ip_hash, count in Counter(row["ip_hash"] for row in host_ip_rows if row["ip_hash"]).items()
    if count > 1
}

print(json.dumps({
    "version": VERSION,
    "patch_id": PATCH_ID,
    "cmdb_counts": cmdb.get("counts"),
    "issues_total": cmdb.get("issues_total"),
    "scan_not_in_cmdb_count": len(scan_not),
    "hosts_total": len(hosts),
    "host_ip_rows": len(host_ip_rows),
    "scan_matches_any_host_by_ip_hash": sum(1 for x in scan_ip_hashes if x in host_ip_hashes),
    "scan_matches_formal_host_by_ip_hash": sum(1 for x in scan_ip_hashes if x in formal_ip_hashes),
    "scan_matches_draft_host_by_ip_hash": sum(1 for x in scan_ip_hashes if x in draft_ip_hashes),
    "duplicate_ip_hash_count": len(dups),
    "duplicate_ip_hash_samples": list(dups.items())[:10],
    "scan_not_in_cmdb_samples_masked": samples
}, ensure_ascii=False, indent=2, sort_keys=True))
PY
```

## 判讀方式

- `scan_matches_any_host_by_ip_hash` 大於 0：主檔其實有資料，通常是資料品質比對邏輯誤判。
- `scan_matches_draft_host_by_ip_hash` 大於 0：資料只在草稿，應顯示「尚未轉正式」，不應直接說 CMDB 無。
- `scan_matches_formal_host_by_ip_hash` 大於 0 但仍出現 `scan_not_in_cmdb`：高度疑似程式 bug。
- 三個 match 都是 0：掃描結果與目前 CMDB 主檔沒有對上，需要查匯入、掃描來源或舊掃描殘留。

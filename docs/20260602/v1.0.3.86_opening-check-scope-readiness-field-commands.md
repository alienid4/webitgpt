# v1.0.3.86 opening-check-scope-readiness field commands

用途：調查「資產管理顯示已納管 100 台，但開門檢查未顯示 100 台」、「某一套系統在資產管理有多台但開門檢查只看到部分平台」、「卡片顯示待連線」等問題。

安全規則：

- 本文件命令輸出預設去識別化。
- 不輸出真實 IP、主機名稱、系統名稱、人名、asset id、system id、內部路徑、帳號或 token。
- 只輸出數量、狀態、平台分類與 12 碼 hash，方便比對但不暴露資料。
- 請勿另外貼 raw Mongo 文件、完整 log、systemctl status、journalctl 或真實畫面文字。

## 1. 一次性調查命令

在 webitgpt 主機執行。`TARGET_SYSTEM` 請填你要查的資產名稱 / 系統名稱關鍵字，例如某套系統名稱。命令不會把大量 JSON 直接印在畫面上，會寫到 `/tmp` 去敏化檔案，畫面只顯示輸出路徑、大小與 SHA256。

```bash
cd /opt/webitgpt
OUT="/tmp/webitgpt_opening_scope_readiness_$(date +%Y%m%d%H%M%S).json"
TARGET_SYSTEM='請在本機填入要查的系統或資產名稱' OUT="$OUT" PYTHONPATH=/opt/webitgpt ./venv/bin/python - <<'PY'
import hashlib
import json
import os
from collections import Counter, defaultdict

from webapp.config import VERSION, PATCH_ID
from webapp.services.host_service import list_hosts
from webapp.services.inspection_service import _system_name as inspection_system_name
from webapp.services.legacy_parity_service import daily_diagnostics
from webapp.services.mongo_service import get_collection

TARGET = (os.environ.get("TARGET_SYSTEM") or "").strip()


def h(value):
    text = str(value or "").strip()
    if not text or text == "-":
        return ""
    return hashlib.sha256(text.encode("utf-8", "ignore")).hexdigest()[:12]


def normalize(value):
    return str(value or "").strip().casefold()


def matches_target(host):
    if not TARGET:
        return False
    needle = normalize(TARGET)
    fields = [
        host.get("asset_name"),
        host.get("system_name"),
        host.get("device_type"),
        host.get("group_name"),
        host.get("hostname"),
        host.get("asset_seq"),
        host.get("apid"),
    ]
    return any(needle and needle in normalize(field) for field in fields)


def public_host_key(host):
    for key in ("asset_seq", "hostname", "ip"):
        if host.get(key):
            return h(host.get(key))
    return ""

hosts = list_hosts(page=1, page_size=20000)["items"]
active_hosts = [host for host in hosts if host.get("status") == "active"]
opening_platforms = ["linux", "windows", "aix", "as400"]
opening_candidates = [host for host in active_hosts if host.get("host_type") in opening_platforms]
not_opening_candidates = [host for host in active_hosts if host.get("host_type") not in opening_platforms]

target_hosts = [host for host in active_hosts if matches_target(host)]
target_opening_hosts = [host for host in target_hosts if host.get("host_type") in opening_platforms]

diagnostics_by_platform = {}
for platform in opening_platforms:
    try:
        data = daily_diagnostics(platform=platform, system_name=TARGET)
        diagnostics_by_platform[platform] = {
            "selected_hosts": data.get("summary", {}).get("hosts"),
            "system_groups": data.get("readiness_summary", {}).get("systems"),
            "checked": data.get("readiness_summary", {}).get("checked"),
            "ready_not_run": data.get("readiness_summary", {}).get("ready"),
            "blocked": data.get("readiness_summary", {}).get("blocked"),
            "pending_items": data.get("summary", {}).get("pending"),
        }
    except Exception as exc:
        diagnostics_by_platform[platform] = {"error_type": type(exc).__name__}

inspection_rows = list(get_collection("inspection_results").find({}, {
    "_id": 0,
    "asset_seq": 1,
    "host_type": 1,
    "status": 1,
    "metric_source": 1,
    "metric_error": 1,
}))
inspection_asset_hashes = {h(row.get("asset_seq")) for row in inspection_rows if row.get("asset_seq")}
target_inspection_matches = [row for row in inspection_rows if h(row.get("asset_seq")) in {h(host.get("asset_seq")) for host in target_hosts}]

# dependency_systems 只輸出 hash 與 host_refs 數量，避免暴露系統名稱。
dependency_matches = []
if TARGET:
    needle = normalize(TARGET)
    for system in get_collection("dependency_systems").find({}, {"_id": 0, "system_id": 1, "display_name": 1, "host_refs": 1, "metadata": 1}):
        text = " ".join(str(system.get(key) or "") for key in ["system_id", "display_name"])
        metadata = system.get("metadata") or {}
        text += " " + " ".join(str(metadata.get(key) or "") for key in ["asset_name", "system_name", "core_name"])
        if needle in normalize(text):
            dependency_matches.append({
                "system_hash": h(system.get("system_id") or system.get("display_name")),
                "display_hash": h(system.get("display_name")),
                "host_refs_count": len(system.get("host_refs") or []),
                "metadata_keys": sorted((system.get("metadata") or {}).keys()),
            })

system_group_counts = defaultdict(Counter)
for host in active_hosts:
    system_hash = h(inspection_system_name(host))
    system_group_counts[system_hash][host.get("host_type") or "unknown"] += 1

summary = {
    "version": VERSION,
    "patch_id": PATCH_ID,
    "target_hash": h(TARGET),
    "asset_master": {
        "hosts_total": len(hosts),
        "active_total": len(active_hosts),
        "active_by_platform": dict(Counter(host.get("host_type") or "unknown" for host in active_hosts)),
        "opening_candidate_total": len(opening_candidates),
        "opening_candidate_by_platform": dict(Counter(host.get("host_type") or "unknown" for host in opening_candidates)),
        "not_opening_candidate_by_platform": dict(Counter(host.get("host_type") or "unknown" for host in not_opening_candidates)),
    },
    "target_asset_scope": {
        "matched_active_hosts": len(target_hosts),
        "matched_opening_candidates": len(target_opening_hosts),
        "matched_by_platform": dict(Counter(host.get("host_type") or "unknown" for host in target_hosts)),
        "matched_status_counts": dict(Counter(host.get("status") or "unknown" for host in target_hosts)),
        "matched_host_hashes": [public_host_key(host) for host in target_hosts[:30]],
    },
    "opening_diagnostics_for_target_by_platform": diagnostics_by_platform,
    "inspection_results": {
        "rows_total": len(inspection_rows),
        "status_counts": dict(Counter(row.get("status") or "unknown" for row in inspection_rows)),
        "metric_source_counts": dict(Counter(row.get("metric_source") or "unknown" for row in inspection_rows)),
        "target_rows": len(target_inspection_matches),
        "target_status_counts": dict(Counter(row.get("status") or "unknown" for row in target_inspection_matches)),
        "active_hosts_without_inspection_result": sum(1 for host in active_hosts if h(host.get("asset_seq")) not in inspection_asset_hashes),
    },
    "topology_dependency_matches": dependency_matches[:20],
    "top_system_group_samples": [
        {"system_hash": key, "count": sum(counter.values()), "platforms": dict(counter)}
        for key, counter in sorted(system_group_counts.items(), key=lambda item: -sum(item[1].values()))[:20]
    ],
}
out = os.environ.get("OUT") or "/tmp/webitgpt_opening_scope_readiness.json"
with open(out, "w", encoding="utf-8") as fh:
    json.dump(summary, fh, ensure_ascii=False, indent=2, sort_keys=True)
print(out)
PY
printf "output=%s\n" "$OUT"
printf "bytes="; wc -c < "$OUT"
printf "sha256="; sha256sum "$OUT" | awk '{print $1}'
```

請只回傳 `/tmp` 內產生的 JSON 檔案內容，或把檔案下載後貼回。若只想先確認摘要，可執行：


若要直接看完整去敏化結果：

```bash

```

如果你已經離開原本 shell，`$OUT` 不見了，用最新檔案路徑：

```bash

```

檔案仍在公司主機 `/tmp`，不會自動上傳。

## 3. 判讀重點

1. `asset_master.active_total` 若為 100，代表資產管理正式納管 100 台。
2. `asset_master.opening_candidate_total` 只統計 `linux / windows / aix / as400`，不含 `end_device / vmware_host / network_device` 等不適合跑主機巡檢的平台。
3. `target_asset_scope.matched_active_hosts` 是該系統在資產主檔找到的台數。
4. `target_asset_scope.matched_by_platform` 可判斷「為何 Linux 分頁只看到 3 台」：若該系統 6 台分散在 Linux、Windows 或其他平台，單一平台頁面只會看到該平台子集合。
5. `opening_diagnostics_for_target_by_platform` 是今日巡檢畫面用的同一套服務邏輯，可比對 UI 數字。
6. `inspection_results.target_status_counts` 若多為 `pending / warn / error`，表示已納入但 L1 實際連線、SSH/WinRM、帳號或 port 條件未完成。
7. `topology_dependency_matches.host_refs_count` 只代表拓撲關聯表保存的 host_refs，不一定等於資產主檔；若與 `target_asset_scope.matched_active_hosts` 不同，需要檢查拓撲同步或系統名稱對應。

## 4. 常見原因對照

| 現象 | 可能原因 | 下一步 |
|---|---|---|
| 資產管理 100 台，開門檢查不是 100 台 | 開門檢查只看主機型平台：Linux、Windows、AIX、AS400；端點、網路設備、VMware host 不會全都進 L1 主機巡檢 | 看 `opening_candidate_total` 與 `not_opening_candidate_by_platform` |
| 某系統資產有 6 台，但 Linux 分頁顯示 3 台 | 目前畫面依平台切分，Linux 分頁只顯示 Linux 子集合 | 看 `matched_by_platform`，再切 Windows / AIX / AS400 分頁 |
| 卡片都是待連線 | 已納入巡檢，但 L1 SSH/WinRM/連線方式、帳號、port 或防火牆尚未通 | 看 `inspection_results.status_counts` 與目標平台帳號設定 |
| 拓撲或核心影響圖台數少於資產主檔 | `dependency_systems.host_refs` 舊資料或系統名稱 / 資產名稱對應不一致 | 看 `topology_dependency_matches` 與資產主檔 matched count |

## 5. 只允許貼回的資料

請只貼回上方 JSON 輸出。不要貼：

- raw Mongo document
- 真實 IP / hostname / 系統名稱 / 人名
- journalctl / systemctl status 原文
- SSH error 原文若含帳號、主機名稱或內部路徑

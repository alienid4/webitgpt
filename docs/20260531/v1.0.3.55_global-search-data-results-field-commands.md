## 安裝後驗證

```bash
curl -fsS http://127.0.0.1:8002/health
curl -fsS 'http://127.0.0.1:8002/search?q=192.168.1.221' | grep '搜尋結果'
curl -fsS 'http://127.0.0.1:8002/search?q=192.168.1.221' | grep '正式資產'
curl -fsS 'http://127.0.0.1:8002/search?q=192.168.1.221' | grep 'CMDB 資產池'
```

## 操作方式

1. 在上方搜尋框輸入 IP、Hostname、資產名稱、人員、APID 或軟體名稱。
2. 系統會顯示分類結果：正式資產、草稿 / 未納管、CMDB 資產池、功能入口。
3. 點擊結果列進入對應資料。

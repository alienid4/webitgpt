# v1.0.3.54 Cumulative CMDB 3.44 to 3.53 Field Commands

Patch：`cumulative-cmdb-3-44-to-3-53`

## 為什麼需要這版

v1.0.3.53 是增量 patch。若現場不是逐版升級，而是從較舊底版直接套 v1.0.3.53，可能會發生版號顯示相同，但功能不同，例如資產管理工具列缺少 `CMDB 資產池`。

v1.0.3.54 是累積 patch，補齊 v1.0.3.44 到 v1.0.3.53 的可部署檔案。

## 下載與安裝

```bash
cd /tmp
curl -LO https://github.com/alienid4/webitgpt/releases/download/v1.0.3.54/webitgpt_v1.0.3.54-patch-cumulative-cmdb-3-44-to-3-53_20260531093000.tar.gz
curl -LO https://github.com/alienid4/webitgpt/releases/download/v1.0.3.54/webitgpt_v1.0.3.54-patch-cumulative-cmdb-3-44-to-3-53_20260531093000.tar.gz.sha256
sha256sum -c webitgpt_v1.0.3.54-patch-cumulative-cmdb-3-44-to-3-53_20260531093000.tar.gz.sha256
tar -xzf webitgpt_v1.0.3.54-patch-cumulative-cmdb-3-44-to-3-53_20260531093000.tar.gz
cd webitgpt_v1.0.3.54-patch-cumulative-cmdb-3-44-to-3-53_20260531093000
sudo bash INSTALL_PATCH.sh
```

## 安裝後驗證

```bash
curl -fsS http://127.0.0.1:8002/health
curl -fsS http://127.0.0.1:8002/hosts | grep 'CMDB 資產池'
curl -fsS http://127.0.0.1:8002/cmdb/workbook | grep '整份治理匯入'
curl -fsS http://127.0.0.1:8002/cmdb/workbook | grep 'CMDB 資產池'
```

## 若仍看不到新功能

```bash
sudo systemctl restart webitgpt
curl -fsS http://127.0.0.1:8002/health
```

瀏覽器請重新整理頁面。若仍看到舊畫面，請確認 `/health` 的 `version` 為 `1.0.3.54`，且 `patch_id` 為 `cumulative-cmdb-3-44-to-3-53`。

## 回滾

```bash
cd /tmp/webitgpt_v1.0.3.54-patch-cumulative-cmdb-3-44-to-3-53_20260531093000
sudo bash ROLLBACK.sh
```

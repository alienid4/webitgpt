## How To Use

1. Open `資產管理`.
2. Click the `草稿` count or filter status to `草稿`.
3. In the draft workflow panel, click `全部草稿轉正式`.
4. Complete records become formal `active` assets.
5. Incomplete records remain draft and are counted as skipped.

## Expected Result

- First CMDB build can promote current drafts in one action.
- New imported or scanned records can still continue through the draft workflow.

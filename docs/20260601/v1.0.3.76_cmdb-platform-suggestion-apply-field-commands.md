## 去敏驗證

```bash
python3 - <<'PY'
import json
import urllib.request

base = "http://127.0.0.1:8002"

with urllib.request.urlopen(base + "/health", timeout=5) as res:
    health = json.loads(res.read().decode("utf-8"))

with urllib.request.urlopen(base + "/api/reports/data-quality", timeout=10) as res:
    quality = json.loads(res.read().decode("utf-8"))

print(json.dumps({
    "version_ok": health.get("version") == "1.0.3.76",
    "patch_id": health.get("patch_id"),
    "quality_status": quality.get("status"),
    "cmdb_issues": (quality.get("summary") or {}).get("cmdb_issues"),
    "platform_mismatch": (quality.get("summary") or {}).get("cmdb_platform_mismatch"),
    "has_apply_route_hint": True
}, ensure_ascii=False, sort_keys=True))
PY
```

## 套用方式

1. 瀏覽器開 `/reports/data-quality`。
2. 若看到 `平台分類需修正` 大於 0，按 `套用平台分類建議`。
3. 回到主管儀表板確認平台分布。

# v1.0.3.71 relation-import-search-ux 現場指令

> 本文件只放可複製的現場指令與去敏化說明，不放真實檔名、IP、主機名、系統名、負責人或原始 Excel 內容。

## 安裝 Patch

```bash
cd /tmp
tar -xzf webitgpt_v1.0.3.71-patch-relation-import-search-ux_YYYYMMDDHHMMSS.tar.gz
cd webitgpt_v1.0.3.71-patch-relation-import-search-ux_YYYYMMDDHHMMSS
WEBITGPT_PIP_MODE=offline bash install.sh
```

## 檢查服務

```bash
curl -fsS http://127.0.0.1:8002/health
curl -fsS -o /tmp/webitgpt_dependencies_check.html -w 'dependencies_http=%{http_code}\n' \
  'http://127.0.0.1:8002/dependencies?view=radial&relation_q=test'
```

## 匯入第二層關聯表

1. 進入「系統拓撲」。
2. 點「匯入第二層關聯表」。
3. 選擇 `.xlsx` 關聯矩陣。
4. 先點「預檢數量」確認來源列、系統數與關聯數。
5. 數量合理後，再點「正式匯入」。
6. 匯入完成後點「查看匯入的關聯」確認資料。

## 查詢匯入結果

在「手動關聯管理」區塊使用「關聯表搜尋」，可輸入：

- 系統名稱
- 系統代號或 APID
- Port
- 服務名稱
- 備註關鍵字

頁首搜尋仍是全域搜尋；關聯表搜尋只查下方關聯表。

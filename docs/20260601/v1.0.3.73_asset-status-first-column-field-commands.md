# v1.0.3.73 asset-status-first-column 現場指令

> 本文件只放去敏化操作方式，不放真實主機名、IP、系統名、owner、asset ID 或原始資料。

## 安裝 Patch

```bash
cd /tmp
tar -xzf webitgpt_v1.0.3.73-patch-asset-status-first-column_YYYYMMDDHHMMSS.tar.gz
cd webitgpt_v1.0.3.73-patch-asset-status-first-column_YYYYMMDDHHMMSS
WEBITGPT_PIP_MODE=offline bash install.sh
```

## 檢查

```bash
curl -fsS http://127.0.0.1:8002/health
curl -fsS -o /tmp/webitgpt_hosts_check.html -w 'hosts_http=%{http_code}\n' \
  'http://127.0.0.1:8002/hosts'
```

## 畫面確認

1. 進入「資產管理」。
2. 表格第一個資料欄應顯示「資產狀態」。
3. 使用中、草稿、待處理、停用與汰除應有不同顏色標籤。
4. Hostname / OS 旁的「未驗證」只代表採證狀態，不代表資產生命週期。

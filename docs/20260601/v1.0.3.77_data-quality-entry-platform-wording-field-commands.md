## 驗證

```bash
python3 - <<'PY'
import json
import urllib.request

base = "http://127.0.0.1:8002"

with urllib.request.urlopen(base + "/health", timeout=5) as res:
    health = json.loads(res.read().decode("utf-8"))

with urllib.request.urlopen(base + "/reports/data-quality", timeout=10) as res:
    page_ok = res.status == 200

print(json.dumps({
    "version_ok": health.get("version") == "1.0.3.77",
    "patch_id": health.get("patch_id"),
    "data_quality_page_ok": page_ok
}, ensure_ascii=False, sort_keys=True))
PY
```

## 操作

1. 進入資產管理。
2. 點上方 `資料品質`。
3. 若仍有「平台分類需修正」，按 `套用平台分類建議`。

注意：這版只修正入口、文案與平台推論規則，不會修改 IP、Hostname、owner、APID 或核心關聯。

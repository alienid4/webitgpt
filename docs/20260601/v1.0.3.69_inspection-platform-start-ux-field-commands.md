# v1.0.3.69 inspection-platform-start-ux field commands

這份指令只輸出狀態碼與版本資訊，不輸出主機名稱、IP、資產編號、使用者或完整日誌。

## 安裝後健康檢查

```bash
curl -fsS http://127.0.0.1:8002/health
```

## 開門檢查頁面檢查

```bash
curl -fsS -o /tmp/webitgpt_inspections_platform_check.html -w 'inspections_http=%{http_code}\n' \
  'http://127.0.0.1:8002/inspections?platform=aix&system=__all__'
```

## 資產列表每頁 100 檢查

```bash
curl -fsS -o /tmp/webitgpt_hosts_page_size_check.html -w 'hosts_http=%{http_code}\n' \
  'http://127.0.0.1:8002/hosts?page_size=100'
```

## 注意

- 不要上傳 `/tmp/webitgpt_inspections_platform_check.html` 或 `/tmp/webitgpt_hosts_page_size_check.html`，因為 HTML 可能含資產名稱。
- 若需要回報，只貼 HTTP code、版本號與畫面截圖，截圖需遮蔽敏感資料。

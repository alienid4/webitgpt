# v1.0.3.79 cmdb-default-connection-by-platform field commands

本文件提供可貼回的去敏化驗證指令。輸出只包含版本、狀態與數量，不輸出主機名稱、IP、人名、資產編號或系統代碼。

## 安裝後驗證

```bash
python3 - <<'PY'
import json
import urllib.request

BASE = "http://127.0.0.1:8002"

def get_json(path):
    with urllib.request.urlopen(BASE + path, timeout=15) as res:
        return json.loads(res.read().decode("utf-8"))

health = get_json("/health")
quality = get_json("/api/reports/data-quality")

print(json.dumps({
    "version": health.get("version"),
    "patch_id": health.get("patch_id"),
    "health_status": health.get("status"),
    "quality_status": quality.get("status"),
    "platform_mismatch_count": quality.get("summary", {}).get("cmdb_platform_mismatch"),
    "missing_connection_count": (quality.get("quality_detail_type_counts") or {}).get("missing_connection", 0)
}, ensure_ascii=False, indent=2, sort_keys=True))
PY
```

## 預期

- `version` 為 `1.0.3.79`
- `patch_id` 為 `cmdb-default-connection-by-platform`
- 可由平台分類推論的資料不應再大量停留在 `missing_connection`

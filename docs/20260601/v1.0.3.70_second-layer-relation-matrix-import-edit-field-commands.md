# v1.0.3.70 second-layer-relation-matrix-import-edit field commands

這份指令避免輸出原始系統名稱、主機名稱、IP、負責人與 Excel 內容。Excel 請放在受控主機本機路徑，匯入後刪除暫存檔。

## 健康檢查

```bash
curl -fsS http://127.0.0.1:8002/health
```

## 第二層關聯匯入乾跑

```bash
cd /opt/webitgpt
./venv/bin/python scripts/import_system_relations.py /path/to/local_relation_workbook.xlsx --dry-run
```

## 正式匯入

```bash
cd /opt/webitgpt
./venv/bin/python scripts/import_system_relations.py /path/to/local_relation_workbook.xlsx --actor field-admin
```

## 頁面檢查

```bash
curl -fsS -o /tmp/webitgpt_dependencies_check.html -w 'dependencies_http=%{http_code}\n' \
  'http://127.0.0.1:8002/dependencies?view=radial'
```

## 注意

- 不要上傳 Excel 原檔或 `/tmp/webitgpt_dependencies_check.html`。
- 若要回報，只貼 dry-run 的 `status/layout/systems/relations/rows` 數字與 HTTP code。

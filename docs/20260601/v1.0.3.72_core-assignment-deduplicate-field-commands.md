# v1.0.3.72 core-assignment-deduplicate 現場指令

> 本文件只放去敏化操作方式，不放真實系統名稱、主機名、IP、owner、asset ID 或原始資料。

## 安裝 Patch

```bash
cd /tmp
tar -xzf webitgpt_v1.0.3.72-patch-core-assignment-deduplicate_YYYYMMDDHHMMSS.tar.gz
cd webitgpt_v1.0.3.72-patch-core-assignment-deduplicate_YYYYMMDDHHMMSS
WEBITGPT_PIP_MODE=offline bash install.sh
```

## 檢查

```bash
curl -fsS http://127.0.0.1:8002/health
curl -fsS -o /tmp/webitgpt_core_assignments_check.html -w 'core_assignments_http=%{http_code}\n' \
  'http://127.0.0.1:8002/superadmin/core-assignments'
```

## 操作說明

1. 進入「系統管理」。
2. 進入「核心歸屬管理」。
3. 同名系統會合併顯示成一列。
4. 若同名底下有多個 system ID，畫面會顯示「已合併 N 個同名系統 ID」。
5. 修改該列核心歸屬後儲存，會同步套用到這些同名 system ID。

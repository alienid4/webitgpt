## 9. Offline / RHEL 9.6 Installation Context

The project must support offline or restricted-network migration.

Known RHEL 9.6 lesson:

- Do not install Rocky Linux release packages on RHEL.
- Do not mix RHEL 9.6 with RHEL/Rocky 9.7 RPMs.
- Avoid protected package replacement such as `systemd`, `glibc`, `redhat-release`, `filesystem`, `setup`.
- Prefer native RHEL repositories when available:
  - BaseOS
  - AppStream
  - Satellite Client repo if present
- Podman/Mongo setup should be robust and idempotent.

Historical failure:

- A previous bundle tried to install Rocky 9.7 packages on RHEL 9.6.
- It caused conflicts with `redhat-release` and dependency mismatches such as `glibc = 2.34-231.el9_7.10`.
- A hotfix skipped protected and incompatible RPMs, but Podman was not installed because dependencies were unavailable from the bundle. MongoDB therefore did not start, and bootstrap failed with `ServerSelectionTimeoutError`.

User preference:

- Podman is acceptable for now.
- Future direction may move from MongoDB to MSSQL.

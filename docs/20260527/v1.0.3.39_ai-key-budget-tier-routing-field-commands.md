# v1.0.3.39 AI KEY 預算階級路由現場指令

這版新增 L1 / L2 / L3 KEY 階級與預算路由。安裝 patch 不需要 API Key；實際 KEY 請由 SuperAdmin 在網頁後台輸入，不要放在文件、聊天、Git 或截圖。

## 安裝

```bash
cd /tmp
curl -LO https://github.com/alienid4/webitgpt/releases/download/v1.0.3.39/webitgpt_v1.0.3.39-patch-ai-key-budget-tier-routing_20260527234500.tar.gz
curl -LO https://github.com/alienid4/webitgpt/releases/download/v1.0.3.39/webitgpt_v1.0.3.39-patch-ai-key-budget-tier-routing_20260527234500.tar.gz.sha256
sha256sum -c webitgpt_v1.0.3.39-patch-ai-key-budget-tier-routing_20260527234500.tar.gz.sha256
tar -xzf webitgpt_v1.0.3.39-patch-ai-key-budget-tier-routing_20260527234500.tar.gz
cd webitgpt_v1.0.3.39-patch-ai-key-budget-tier-routing_20260527234500
sudo bash INSTALL_PATCH.sh /opt/webitgpt
```

## 驗證

```bash
curl -fsS http://127.0.0.1:8002/health
curl -fsS http://127.0.0.1:8002/ready
systemctl is-active webitgpt
grep -n "預算與 KEY 階級路由" /opt/webitgpt/webapp/templates/ai_settings.html
grep -n "KEY 階級與預算上限" /opt/webitgpt/webapp/templates/token_costs.html
```

## 後台操作

1. 開啟 `http://<host>:8002/superadmin/ai`
2. 啟用 AI provider。
3. 啟用「預算路由」。
4. 設定全域月預算。
5. 依序設定 L1 / L2 / L3：
   - L1：低成本或不使用 AI。
   - L2：一般摘要、簡單分類。
   - L3：深度判讀，成本最高。
6. 設定超額策略：
   - `Script fallback`：最安全，超額後回既有規則。
   - `改用最低階 KEY`：仍允許 AI，但降成本。
   - `停用 AI 判讀`：嚴格控費。

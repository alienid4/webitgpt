# v1.0.3.34 CMDB Test Clear Field Commands

Date: 2026-05-27

Use this before testing CMDB CSV/Excel import, scan-created drafts, and draft bulk actions.

This clears CMDB asset/test data only. It keeps users, API tokens, feature flags, system settings, account inventory, NMON data, and release files.

## What This Clears

- `hosts`
- `ip_reservations`
- `network_scan_reports`
- `host_lifecycle_events`
- `host_identity_checks`
- `asset_identity_refresh_runs`
- Host file directories under `/opt/webitgpt/data/hosts`
- Hostname link directories under `/opt/webitgpt/data/hosts_by_hostname`

## Clear CMDB Test Data

```bash
cd /opt/webitgpt
sudo /opt/webitgpt/venv/bin/python - <<'PY'
from __future__ import annotations

import json
import shutil
from datetime import datetime
from pathlib import Path

from bson import json_util

from webapp import config
from webapp.services.mongo_service import get_collection

stamp = datetime.now().strftime("%Y%m%d%H%M%S")
backup_root = Path(config.BACKUP_DIR) / "manual_cmdb_clear" / stamp
backup_root.mkdir(parents=True, exist_ok=True)

collections = [
    "hosts",
    "ip_reservations",
    "network_scan_reports",
    "host_lifecycle_events",
    "host_identity_checks",
    "asset_identity_refresh_runs",
]

summary = {"backup": str(backup_root), "collections": {}, "moved_dirs": []}

for name in collections:
    col = get_collection(name)
    rows = list(col.find({}))
    backup_file = backup_root / f"{name}.jsonl"
    with backup_file.open("w", encoding="utf-8") as fh:
        for row in rows:
            fh.write(json_util.dumps(row, ensure_ascii=False) + "\n")
    deleted = col.delete_many({}).deleted_count
    summary["collections"][name] = {"backed_up": len(rows), "deleted": deleted}

for raw_path in [config.HOSTS_DIR, config.HOSTNAME_LINK_DIR]:
    path = Path(raw_path)
    if path.exists():
        target = backup_root / path.name
        shutil.move(str(path), str(target))
        path.mkdir(parents=True, exist_ok=True)
        summary["moved_dirs"].append({"from": str(path), "to": str(target)})

print(json.dumps(summary, ensure_ascii=False, indent=2, default=str))
PY

sudo systemctl restart webitgpt
curl -fsS http://127.0.0.1:8002/health
```

## Restore From Backup If Needed

Replace `<STAMP>` with the backup timestamp printed by the clear command.

```bash
cd /opt/webitgpt
export CMDB_CLEAR_BACKUP=/opt/webitgpt/backup/manual_cmdb_clear/<STAMP>

sudo /opt/webitgpt/venv/bin/python - <<'PY'
from __future__ import annotations

import os
from pathlib import Path

from bson import json_util

from webapp.services.mongo_service import get_collection

backup_root = Path(os.environ["CMDB_CLEAR_BACKUP"])
collections = [
    "hosts",
    "ip_reservations",
    "network_scan_reports",
    "host_lifecycle_events",
    "host_identity_checks",
    "asset_identity_refresh_runs",
]

for name in collections:
    backup_file = backup_root / f"{name}.jsonl"
    col = get_collection(name)
    col.delete_many({})
    rows = []
    if backup_file.exists():
        with backup_file.open("r", encoding="utf-8") as fh:
            rows = [json_util.loads(line) for line in fh if line.strip()]
    if rows:
        col.insert_many(rows)
    print(f"{name}: restored {len(rows)}")
PY

sudo systemctl restart webitgpt
curl -fsS http://127.0.0.1:8002/health
```

Host file directories are also backed up under the same folder. Restore those manually only if you need the old per-host files back.

# v1.0.3.38 global judgement source visibility field commands

本文件提供現場可直接複製的安裝與驗證指令。正式 API Key 不要貼在文件或聊天中；若未設定 API Key，webitgpt 仍會以 Script / Rule / NMON / CMDB 既有判斷保底。

## 下載與安裝

```bash
cd /tmp
curl -LO https://github.com/alienid4/webitgpt/releases/download/v1.0.3.38/webitgpt_v1.0.3.38-patch-global-judgement-source-visibility_20260527233600.tar.gz
curl -LO https://github.com/alienid4/webitgpt/releases/download/v1.0.3.38/webitgpt_v1.0.3.38-patch-global-judgement-source-visibility_20260527233600.tar.gz.sha256
sha256sum -c webitgpt_v1.0.3.38-patch-global-judgement-source-visibility_20260527233600.tar.gz.sha256
tar -xzf webitgpt_v1.0.3.38-patch-global-judgement-source-visibility_20260527233600.tar.gz
cd webitgpt_v1.0.3.38-patch-global-judgement-source-visibility_20260527233600
sudo bash INSTALL_PATCH.sh /opt/webitgpt
```

## 健康檢查

```bash
curl -fsS http://127.0.0.1:8002/health

```

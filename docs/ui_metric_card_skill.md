# 統計格 UI Skill

## 固定規則

所有顯示統計數字、狀態數量、彙總數量的格子，都必須可以點擊進入對應細項內容。

這類元件包含 `.metric`、`.metric-card`、帳號盤點統計、資產統計、開門檢查統計、軟體盤點統計、IPAM 統計、拓撲對帳統計、系統管理統計、健康檢查統計與 Patch 統計。

## 實作方式

- 統計格必須使用 `<a class="metric"...>` 或同等可點擊元件。
- 不可使用 `<div class="metric">` 或 `<div class="metric-card">` 做純顯示卡。
- `href` 必須指向明細頁、同頁錨點、篩選後清單或對應管理頁。
- 如果目前沒有專屬明細頁，至少要導到同頁下方的明細區，並在明細區加上穩定 `id`。
- 統計格點擊後不能只改 URL 沒內容；目標區要能讓使用者看見這個數字由哪些資料組成。

## 設計理由

主管或維運人員看到數字時，下一個問題一定是「是哪幾筆」。統計格如果不能下鑽，就只能靠人工猜測或到處找資料，這會讓報表變成黑箱。

# v1.0.3.48 CMDB Workbook Asset Pool Field Commands

Use these commands from the installed webitgpt host.

## Verify Service

```bash
curl -fsS http://127.0.0.1:8002/health
curl -fsS http://127.0.0.1:8002/ready
```

## Verify New Page

```bash
curl -fsS http://127.0.0.1:8002/cmdb/workbook | grep "CMDB Excel"
```

## Install Patch

```bash
tar -xzf webitgpt_v1.0.3.48-patch-cmdb-workbook-asset-pool_20260529115500.tar.gz
cd webitgpt_v1.0.3.48-patch-cmdb-workbook-asset-pool_20260529115500
sudo bash INSTALL_PATCH.sh
```

## Post Install Verify

```bash
curl -fsS http://127.0.0.1:8002/health
curl -fsS http://127.0.0.1:8002/ready
curl -fsS http://127.0.0.1:8002/cmdb/workbook | grep "CMDB Excel"
```

## Rollback

```bash
cd webitgpt_v1.0.3.48-patch-cmdb-workbook-asset-pool_20260529115500
sudo bash ROLLBACK.sh
```

## Operator Flow

1. Open `/cmdb/workbook`.
2. Upload the company `.xlsx` workbook and run preview.
3. If the hardware sheet looks correct, run hardware draft import.
4. Open asset drafts and promote only the hosts that should be managed by inspection.
5. Import data, software, and people sheets into the asset pool for later relationship governance.

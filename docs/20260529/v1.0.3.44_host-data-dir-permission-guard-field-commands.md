# v1.0.3.44 主機草稿儲存 Permission denied 現場修復指令

用途：畫面顯示類似以下錯誤時使用：

```text
儲存失敗：[Errno 13] Permission denied: '/opt/webitgpt/data/hosts/...'
```

## 1. 確認版本

```bash
curl -fsS http://127.0.0.1:8002/health
```

## 2. 修復資料目錄權限

```bash
sudo mkdir -p /opt/webitgpt/data/hosts /opt/webitgpt/data/hostnames /opt/webitgpt/data/archive /opt/webitgpt/logs /opt/webitgpt/backup
sudo chown -R sysinfra:itagent /opt/webitgpt/data /opt/webitgpt/logs /opt/webitgpt/backup
sudo chmod -R u+rwX,g+rwX /opt/webitgpt/data /opt/webitgpt/logs /opt/webitgpt/backup
sudo systemctl restart webitgpt
curl -fsS http://127.0.0.1:8002/health
curl -fsS http://127.0.0.1:8002/ready
```

## 3. 重新測試

回到畫面重新按一次「儲存資產」。

## 4. 若仍失敗，收集 log

```bash
sudo journalctl -u webitgpt -n 200 --no-pager | egrep -A30 'host_edit_submit failed|host_new_submit failed|host directory sync skipped|Permission denied|Traceback'
```

## 5. 檢查目錄權限

```bash
ls -ld /opt/webitgpt/data /opt/webitgpt/data/hosts /opt/webitgpt/data/hostnames /opt/webitgpt/logs /opt/webitgpt/backup
ps -ef | grep -E 'gunicorn|webitgpt' | grep -v grep
```

# 清冊表格排序 SKILL

## 目的

所有清冊型、報表型、盤點型表格都要能直接點欄位排序，避免使用者為了找資料還要匯出 Excel。

## 固定規則

- 表格使用 `table.data-table` 時，預設啟用欄位排序。
- 欄位標題點一下升冪，再點一下降冪。
- `選取`、`操作`、`展開`、`明細` 這類功能欄不可排序，請加 `data-sortable="false"`。
- 一筆資料若有展開明細列，排序時明細列必須跟著主資料列移動，不可拆散。
- 表格若真的不能排序，才使用 `data-no-sort="true"`，並在畫面或程式註解說明原因。
- 新增清冊頁面時，優先沿用 `.data-table`，不要為單一頁面重做一套排序邏輯。

## 驗證方式

1. 點任一資料欄位標題，資料列順序會改變。
2. 再點一次同欄位，排序方向會反轉。
3. 點 `選取`、`操作`、`展開` 欄位不應觸發排序。
4. 有展開明細的表格，排序後展開內容仍要跟在原本那筆資料下方。

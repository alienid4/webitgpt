# v1.0.3.61 - Topology Searchable Selector

## Summary

This patch makes the topology system selector usable when CMDB data grows. Operators can type a clue before choosing the core/system, instead of scrolling a long native dropdown.

## Changes

- Adds searchable filter inputs to the core impact selector and the system relation selector.
- Keeps the original `center` select in the form, so existing URLs, fullscreen mode, and node-click behavior remain compatible.
- Search matches system display name, system id, owner, host references, and description.
- Shows a small match count while typing.

# v1.0.3.36 - ai-judgement-source-ux

Release date: 2026-05-27 22:50 +08:00

## Changes

- Added the AI judgement source UX design rule: Shell collects evidence, AI interprets, Script takes over when AI is unavailable.
- Defined consistent UI/report source labels for Script, API Key, AI, AI + Script, Script fallback, and insufficient evidence.
- Defined L1/L2/L3 routing defaults: L1 Script only, L2 optional lightweight AI, L3 AI-first deep judgement with Script fallback.
- Added the `webitgpt-ai-judgement-ui` Codex skill for future webitgpt AI judgement, fallback, debug, and source-badge work.
- Updated the architecture slide HTML and generation prompt to highlight AI judgement source visibility and fallback design.

## Why

AI judgement should be visibly different from script judgement. Operators must know whether a result came from fixed rules, API verification, AI interpretation, or fallback. This keeps AI flexible while preserving evidence traceability and operational continuity.

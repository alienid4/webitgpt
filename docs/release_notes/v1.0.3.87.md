# v1.0.3.87 system-name-alias-governance

## 重點

- 今日巡檢、拓撲同步與 CMDB 關聯總覽共用系統名稱正規化規則。
- 將常見別名與誤植，例如「證券 / 證卷 / 証券」，歸併為同一套系統口徑。
- 開門檢查加入折疊式「範圍說明」，說明正式資產、可巡檢主機與未納入 L1 主機巡檢的資產類型。

## 使用者影響

- CMDB 匯入後，只要資產狀態為正式且平台屬於 Linux / Windows / AIX / AS400，就會自動進入開門檢查候選。
- 端點、網路設備、VMware host 仍會保留在 CMDB 與資產總覽，但不會出現在 L1 主機巡檢範圍。
- 同一套系統若因文字誤差被寫成不同名稱，系統會先用正規化規則合併顯示，降低人工修資料前的誤判。

# v1.0.3.92 - release-tar-root-install-layout

## 變更內容

- 修正 Release patch tar 結構。
- 解開 patch tar 後，第一層固定提供：
  - `install.sh`
  - `payload/`
- 保留 v1.0.3.91 的資產管理清單序號欄位修正。

## 為什麼修正

v1.0.3.91 的程式內容正確，但 Release tar 解開後需要先進入套件目錄才會看到 `install.sh`。依現場操作規則，Release tar 解開後第一層就應該能看到 `install.sh`，避免使用者找不到安裝入口。

## 驗證

- `python -m pytest tests/test_ui_contracts.py -q`
- `python -m pytest tests/test_asset_account_ui.py -q`
- `python -m pytest -q`
- 檢查 tar 內容第一層包含 `install.sh` 與 `payload/`

## 安裝

```bash
bash install.sh
```

# webitgpt v1.0.3.48 - CMDB Workbook Asset Pool

Build time: 2026-05-29 11:55 +08:00

## What Changed

- Added a CMDB Excel workbook import wizard.
- Workbook preview now reads multiple sheets and classifies hardware, data, software, and people sheets.
- Hardware rows are imported as draft hosts only. They do not become formally managed inspection targets until promoted.
- Data, software, and people rows are imported into `cmdb_asset_pool`.
- Data assets try to link back to existing hosts by hostname or IP, and unmatched rows are marked for later governance.

## Why It Matters

This allows a large company CMDB workbook to enter the platform safely. The asset pool can hold broad inventory first, while operators gradually select which hosts should enter managed inspection.

## Known Notes

- Existing host import API behavior is preserved.
- The new workbook wizard is designed for `.xlsx`.
- Hardware sheet import creates draft hosts so the operator can validate owner, environment, connection method, and L1/L2/L3 credentials before promotion.

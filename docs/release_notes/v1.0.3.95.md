# v1.0.3.95 - cumulative-ui-parity-release

## 變更內容

- 發布累積式 UI patch，補齊目前 main 的 `webapp/` 應用程式檔案。
- 修正公司主機安裝 v1.0.3.94 後，版本號已更新但資產清單仍顯示舊欄位的問題。
- 資產管理清單第一欄維持「序號」，以頁面順序顯示 1-99999，不再顯示 `HW-...` 資產流水號。
- Release TAR 保持 v1.0.3.89 相容版型，仍使用資料夾內 `install.sh`。
- `install.sh` / `ROLLBACK.sh` 保持 `sh install.sh` 相容與 Linux LF 換行。

## 修正原因

v1.0.3.94 主要修正 Release installer 相容性，payload 範圍較小；若公司主機從較舊版本直接套用 v1.0.3.94，可能沒有同步取得先前已在測試主機驗證過的 UI template 與 static 檔案。

v1.0.3.95 改為累積式 UI parity patch，確保公司主機安裝後與測試主機畫面一致。

## 安裝方式

```bash
tar -xzf webitgpt_v1.0.3.95-patch-cumulative-ui-parity-release_<yyyymmddHHMM>.tar.gz
cd webitgpt_v1.0.3.95-patch-cumulative-ui-parity-release_<yyyymmddHHMM>
sudo bash install.sh /opt/webitgpt
```

若現場外層腳本呼叫 `sh install.sh`，本版也會自動轉交 bash 執行。

## 驗證

- `python -m pytest -q`
- Linux 端驗證 `sh install.sh /tmp/not_exist_webitgpt` 只回報 `APP_HOME not found`。
- 測試主機實際安裝後 `/health` 回報 `version=1.0.3.95`。
- 資產管理頁確認第一欄為「序號」，資料列顯示 1、2、3，不顯示 `HW-...`。

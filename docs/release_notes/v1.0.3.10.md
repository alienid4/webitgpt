# v1.0.3.10 - 核心影響焦點系統口徑

Build time: 2026-05-26 08:25:00 +08:00
Patch ID: core-impact-system-focus-scope

## 變更內容

- 修正核心系統影響圖在選取單一系統時，仍把同核心所有系統都畫出的問題。
- 選核心時維持核心總覽；選系統時改為只顯示焦點系統、直接關聯系統與其主機 / IP。
- 右側影響面板新增「檢視口徑」，讓使用者知道目前是核心總覽或焦點系統。
- 補上焦點系統測試，確認選 `SYS-DEBIAN` 時不會帶出 `SYS-ROCKY` 與其主機。

## 驗證方式

```bash
python -m py_compile webapp/config.py webapp/services/dependency_service.py webapp/templates/dependencies.html
python -m pytest tests/test_app.py tests/test_ui_contracts.py -q
python -m pytest -q
```

## 已知風險

- 若焦點系統尚未建立 CMDB 關聯，畫面會只顯示該系統與它底下主機，這是目前預期行為。

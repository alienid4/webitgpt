# v1.0.3.62 - Asset Name First Topology Labels

## Summary

This patch makes topology and asset workflows use the same human-facing term: `資產名稱 / 系統名稱`. The UI now leads with asset name and keeps the system id as a stable identifier behind it.

## Changes

- Topology core/system selectors now say `選擇資產名稱 / 系統名稱`.
- Topology search placeholders now search by asset name, system name, code, host, owner, and description.
- Host-derived topology system display names prefer `asset_name`, while `system_id` remains based on stable system data to avoid breaking existing links.
- Asset management search and opening-check search copy now use `資產名稱 / 系統名稱`.

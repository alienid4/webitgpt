# v1.0.3.89 topology-host-alias-backfill

## 變更內容

- 修正核心系統影響圖在選定系統時，只依賴 `host_refs` 或單一系統欄位，導致同一套系統的部分主機沒有被畫出來的問題。
- 拓撲補主機時，改用系統顯示名稱、metadata 內的資產名稱 / 系統名稱，以及主機端的資產名稱、系統名稱、設備名稱等候選欄位一起比對。
- 延續系統名稱正規化與別名治理，支援常見同音或異體字差異，降低 CMDB 匯入後還要人工修正的機率。
- 移除程式內既有 lab 本機採證預設值；需要本機採證例外時，請改用 `WEBITGPT_LOCAL_PROBE_HOSTS` 環境變數設定。

## 注意

- 本版不會自動補齊 CMDB 欄位，只改善已有資產資料進入拓撲時的比對與補畫邏輯。
- 若公司環境仍顯示數量不符，請使用 GitHub docs 內的去敏化現場指令產出摘要，不要回傳原始主機清單或個資。

# webitgpt v1.0.2.96 app offline install baseline

Build time: 2026-05-20 22:49 +08:00

## Scope

This release asset is an **application offline bundle**. It includes webitgpt source code, install scripts, service files, documentation, and a Python 3.9 Linux wheelhouse.

It does **not** include a full OS RPM repository, MongoDB server package/container image, `nmap` RPM, or `nmon` RPM. If the target host cannot access the internet and these OS packages are not already installed, prepare a separate OS prerequisite bundle before running `INSTALL.sh`.

## Changes

- Added private GitHub repository workflow for webitgpt.
- Added clean offline install runbook for migrating from `192.168.1.221` to a new host such as `192.168.1.224`.
- Added full offline package verification script.
- Repaired interactive `INSTALL.sh` template so operators can read prompts during offline install.
- Added CMDB CSV example for first import without carrying lab/test data.
- Removed the old hard-coded superadmin password from bootstrap and validation defaults.

## Verification

- Built application offline tarball with Python 3.9 Linux wheelhouse.
- Verified archive content with `scripts/verify_offline_bundle.ps1`.
- Confirmed archive excludes runtime folders and Mongo dumps.

## Install Command

```bash
cd /tmp
tar -xzf webitgpt_offline_1.0.2.96-offline-onekey-install_*.tar.gz
cd webitgpt_offline_1.0.2.96-offline-onekey-install_*
sudo bash INSTALL.sh
curl http://localhost:8002/health
systemctl status webitgpt --no-pager
```

## Required Target Host Baseline

The target host must already have, or receive from a separate RPM bundle:

- `python3`
- Python venv support
- `tar`
- `curl`
- `rsync` recommended
- `nmap` for IPAM/network scan
- `nmon` for performance raw collection
- a reachable MongoDB service, or a separately installed MongoDB instance/container

## Known Risk

- If the target host cannot access OS repositories and lacks required OS packages, this app bundle alone is not enough.
- If the target host has no MongoDB, this app bundle alone is not enough.
- Prepare compatible Rocky/RHEL 9 prerequisites with `scripts/prepare_offline_prereq_bundle.sh` from a connected Rocky/RHEL 9 host. That separate bundle is responsible for OS RPMs, `nmap`, `nmon`, `podman`, and MongoDB container image.
- `192.168.1.224` SSH is reachable, but `sysinfra` key login was not available during preparation.

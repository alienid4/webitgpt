# webitgpt v1.0.2.96 offline install baseline

Build time: 2026-05-20 22:05 +08:00

## Changes

- Added private GitHub repository workflow for webitgpt.
- Added clean offline install runbook for migrating from `192.168.1.221` to a new host such as `192.168.1.224`.
- Added full offline package verification script.
- Repaired interactive `INSTALL.sh` template so operators can read prompts during offline install.
- Added CMDB CSV example for first import without carrying lab/test data.
- Removed the old hard-coded superadmin password from bootstrap and validation defaults.

## Verification

- Built full offline tarball with Python 3.9 Linux wheelhouse.
- Verified archive content with `scripts/verify_offline_bundle.ps1`.
- Confirmed archive excludes runtime folders and Mongo dumps.

## Install Command

```bash
cd /tmp
tar -xzf webitgpt_offline_1.0.2.96-offline-onekey-install_*.tar.gz
cd webitgpt_offline_1.0.2.96-offline-onekey-install_*
sudo bash INSTALL.sh
curl http://localhost:8002/health
systemctl status webitgpt --no-pager
```

## Known Risk

- If the target host cannot access OS repositories and lacks `python3`, `curl`, or `tar`, prepare compatible RPMs with `scripts/prepare_offline_rpms.sh` and include them in the bundle.
- `192.168.1.224` SSH is reachable, but `sysinfra` key login was not available during preparation.

# v1.0.4.8 - asset-breakdown-on-demand-results

## Purpose

This patch makes the asset management page more compact. Platform and environment breakdowns now follow the same on-demand pattern as the CMDB relationship coverage detail: click the metric first, then search or show all before the result list expands.

## Changes

- Platform and environment metric cards open a compact breakdown search panel.
- Breakdown result rows remain hidden until the operator searches or clicks show all.
- Asset detail rows still remain hidden on the default page and only expand after search, filtering, or show all.
- Added UI contract checks for the breakdown filter DOM and JavaScript behavior.

## Install

```bash
tar -xzf webitgpt_v1.0.4.8-patch-asset-breakdown-on-demand-results_<timestamp>.tar.gz
cd webitgpt_v1.0.4.8-patch-asset-breakdown-on-demand-results_<timestamp>
sudo bash install.sh /opt/webitgpt
```

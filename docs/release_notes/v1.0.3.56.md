# v1.0.3.56 - Optional Global Search Entry

## 目的

修正使用者感覺上方搜尋「一定要填」的問題。

搜尋框現在可以空白送出。空白搜尋不會被導回資產列表，而是進入搜尋入口頁，顯示最近資料與常用入口，讓使用者可以先看再決定要找什麼。

## 變更內容

- `/search` 不帶 `q` 或 `q` 空白時，顯示搜尋入口頁。
- 搜尋入口頁顯示最近正式資產、最近草稿 / 未納管、最近 CMDB 資產池。
- 搜尋入口頁顯示常用功能入口。
- 搜尋頁文案改成「不必先填完整條件」。

## 驗證方式

- `python -m compileall webapp`
- `python -m pytest -q`
- 221 測試主機確認 `/search` 回 HTTP 200。
- 221 測試主機確認 `/search` 顯示 `搜尋入口` 與 `不必先填完整條件`。
- 221 測試主機確認 `/search?q=192.168.1.221` 仍可顯示分類搜尋結果。

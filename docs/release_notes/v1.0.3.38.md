# v1.0.3.38 - global-judgement-source-visibility

Release date: 2026-05-27 23:45 +08:00

## Changes

- Added judgement source legends to dashboard, reports, data quality, CMDB import, NMON, topology, and account inventory pages.
- Standardized visible badges for CMDB, Script, Rule, API, NMON, AI-ready, AI + Script, fallback, and insufficient evidence.
- Made the fallback model explicit: API Key is not required for existing operation; when AI is unavailable, Script / Rule / NMON / CMDB checks continue to work.

## Why

v1.0.3.37 made AI judgement visible on post-install and L3 deep checks. This patch extends the same visual language across the main operational surfaces so users can see where each conclusion comes from before trusting it.

# v1.0.3.57 - Draft Partial Save Governance

## Summary

This patch fixes the asset draft workflow. Draft and pending-data hosts can now be saved with partial CMDB fields, while formal assets still require full governance fields before they can enter normal inspection.

## Changes

- Draft-like statuses (`draft`, `pending_ip`, `pending_data`, `pending_deploy`) use lenient validation.
- Formal statuses still use strict validation for required CMDB fields, OS, and connection data.
- The asset edit page only renders hard `required` fields for formal assets.
- Host service now imports and raises `ValidationError` consistently for hostname conflicts.

## Verification

- `python -m compileall webapp`
- `python -m pytest -q`
- Test host edit draft page on 221 and confirm partial draft save is not blocked by browser required fields.
- Test active/formal save still blocks missing CMDB fields.

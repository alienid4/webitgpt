# v1.0.4.11 - lazy-host-asset-list-query

## 重點

- 資產管理頁預設只載入摘要與精簡入口。
- 資產大表不再於初始進頁時查詢與渲染。
- 搜尋、篩選、點數字卡、翻頁、包含下線或按「顯示全部」後才載入明細。

## 使用方式

```bash
tar -xzf webitgpt_v1.0.4.11-patch-lazy-host-asset-list-query_<timestamp>.tar.gz
cd webitgpt_v1.0.4.11-patch-lazy-host-asset-list-query_<timestamp>
sudo bash install.sh /opt/webitgpt
```

## 驗證

```bash
curl -sS http://127.0.0.1:8002/health
curl -sS -o /tmp/webitgpt_hosts_default.html -w "%{http_code}\n" http://127.0.0.1:8002/hosts
curl -sS -o /tmp/webitgpt_hosts_all.html -w "%{http_code}\n" "http://127.0.0.1:8002/hosts?show_assets=1"
```

預期：

- `/health` 顯示 `version` 為 `1.0.4.11`。
- `/hosts` 可快速載入摘要與「資產明細」入口。
- `/hosts?show_assets=1` 才載入資產明細表格。

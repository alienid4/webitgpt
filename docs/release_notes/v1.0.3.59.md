# v1.0.3.59 - Saved Filter Nonblocking

## Summary

This patch removes an unnecessary browser-required blocker from the asset management page. The saved-filter name is optional and should not stop normal asset browsing or filtering.

## Changes

- The saved-filter name input no longer uses HTML `required`.
- If the user saves a filter without a name, the system generates a name from the selected conditions.
- Empty filters are still rejected, so the system does not create meaningless saved views.

## Verification

- `python -m compileall webapp`
- `python -m pytest -q`
- Confirm `/hosts` does not show the browser tooltip `請填寫這個欄位。` when using normal filters.

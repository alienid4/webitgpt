# v1.0.3.72 - core-assignment-deduplicate

## 重點

- 核心歸屬管理改為依系統顯示名稱合併同名列。
- 同名列會提示底層 system ID 數量，避免誤以為資料消失。
- 儲存核心歸屬時會同步套用到同名底下所有 system ID。

## 為什麼要改

第二層關聯表與主機清冊可能用不同 system ID 建立同一個顯示名稱。原本核心歸屬清單以 system ID 為列，所以同名系統會看起來重複。本版改為管理畫面合併顯示，但不刪除底層資料。

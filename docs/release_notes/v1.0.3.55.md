# v1.0.3.55 - Global Search Data Results

## 目的

讓上方搜尋真的可以拿來找資料，而不是只能找功能入口。

使用者輸入 IP、Hostname、資產名稱、人員、AP 或軟體名稱時，系統會先整理資料命中位置，再把結果分成正式資產、草稿 / 未納管、CMDB 資產池與功能入口。

## 變更內容

- 新增全域資料搜尋服務。
- 搜尋正式資產與草稿主機，涵蓋資產編號、Hostname、IP、網段、資產名稱、系統名稱、APID、負責人與備註。
- 搜尋 CMDB 資產池，涵蓋資料資產、軟體 / AP、人員窗口、主機證據與待分類。
- 搜尋結果頁新增分類摘要，讓使用者一眼知道資料在正式資產、草稿、資產池或功能入口。
- 若沒有資料結果且只命中一個功能入口，保留原本快速跳轉行為。

## 驗證方式

- `python -m compileall webapp`
- `python -m pytest -q`
- 221 測試主機確認 `/search?q=192.168.1.221` 顯示搜尋結果頁。
- 221 測試主機確認搜尋結果頁包含 `正式資產`、`草稿 / 未納管`、`CMDB 資產池`、`功能入口`。

## 使用方式

在任一頁上方搜尋框輸入：

- IP，例如 `192.168.1.221`
- Hostname，例如 `secansible`
- 資產名稱或系統名稱
- APID
- 人員姓名、保管人或使用單位

系統會顯示分類結果，點擊結果列可進入對應資產或 CMDB 資產池項目。

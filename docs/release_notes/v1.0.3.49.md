# v1.0.3.49 - CMDB Workbook Governed Import

## 變更摘要

- CMDB Excel 匯入新增「整份治理匯入」。
- Excel 可以整份接收，但不會直接污染正式資產。
- 硬體列會分流：
  - 既有正式主機：只進資產池留匯入證據。
  - 新主機：建立幽靈候選草稿，人工確認後才正式納管。
  - 缺 IP / Hostname：進待分類。
- 資料、軟體、人員列進 `cmdb_asset_pool`。
- 未知工作表隔離為待分類，後續再補規則。
- 匯入精靈 UI 簡化為「預檢」與「整份治理匯入」，進階動作收合。
- 主管儀表板區分正式納管資產與幽靈候選 / 草稿。

## 驗證

- `python -m compileall webapp`
- `python -m pytest -q tests/test_asset_account_ui.py -q`

## 使用方式

1. 開啟 `/cmdb/workbook`。
2. 上傳公司 CMDB `.xlsx`。
3. 先執行「預檢整份 Excel」。
4. 確認幽靈候選、既有正式、資產池與待分類數量。
5. 執行「整份治理匯入」。
6. 到資產管理草稿區挑選要正式納管的幽靈候選。

## 注意事項

- 這版不會把 Excel 硬體列直接轉正式主機。
- 正式資產仍需人工確認後才晉升。
- 未知 sheet 不會丟棄，會進待分類。

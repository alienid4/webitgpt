# v1.0.3.60 - Initial Draft Promote All

## Summary

This patch adds a build-time workflow for the first CMDB import. Operators can turn all existing draft assets into formal assets in one action, while future imported or scanned records can continue to use the draft workflow.

## Changes

- Adds a visible `全部草稿轉正式` action in the draft workflow panel.
- Adds `scope=all_drafts` support to the bulk promote route.
- Adds `list_draft_host_keys()` to collect all current draft hosts.
- Bulk promote now handles each draft independently. Complete records become `active`; incomplete records are skipped and counted instead of failing the whole batch.

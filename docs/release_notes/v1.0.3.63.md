# v1.0.3.63 - Business System Only Topology

## Summary

This patch prevents ordinary hosts from being promoted into topology systems. A topology system is now created only when the asset has a real `asset_name` or `system_name`.

## Changes

- Stops using hostname as a fallback system name in topology system sync.
- Host-to-system mapping now also requires `asset_name` or `system_name`.
- Keeps asset name first when both asset name and system name exist.
- Cleans stale host-derived synchronized systems that have no asset name and no system name.

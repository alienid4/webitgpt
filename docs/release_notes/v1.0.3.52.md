# v1.0.3.52 - CMDB Asset Pool Empty Diagnosis

## 變更摘要

- CMDB 資產池為 0 時新增診斷區塊。
- 診斷區塊會顯示：
  - 目前主機清冊總數
  - 最近主機匯入新增 / 更新數
  - 最近 Excel 預檢列數
  - 最近資產池 / 治理匯入數
- 空表格文案改為明確說明：主機匯入在資產清冊，Excel 預檢不會寫入資產池。
- 新增下一步按鈕：去資產清冊看已匯入主機、回上方執行整份治理匯入。

## 現場原因說明

如果畫面顯示 `CMDB 資產池 Total 0`，但剛剛明明匯入成功，通常代表使用的是 `新增 / 匯入主機` 的主機匯入流程。該流程會寫入 `hosts`，不會寫入 `cmdb_asset_pool`。

`cmdb_asset_pool` 只接收：

- `整份治理匯入`
- `只匯入資產池`
- 既有正式主機的硬體證據
- 資料、軟體、人員、待分類資料

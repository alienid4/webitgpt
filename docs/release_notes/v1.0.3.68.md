# v1.0.3.68 - Topology Core Assignment Management

## Purpose

Add a UI for managing the first-layer core assignment of second-layer systems. Operators no longer need code changes to move systems between core groups in the core impact topology.

## What Changed

- Added `系統管理 > 規則與治理 > 核心歸屬管理`.
- Added batch save for system-to-core assignment.
- Core assignment is stored in `dependency_systems.metadata.core_name`.
- Host-to-topology sync preserves manual core assignment instead of overwriting it.
- Global search can find `核心歸屬管理`.

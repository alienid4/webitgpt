## Changes

- Added a visible `資料品質` entry in asset management.
- Clarified the wording difference between `OS 版本` and `平台分類`.
- Red Hat, RHEL, CentOS, Ubuntu, Debian, Rocky, SUSE, Oracle Linux and similar OS values are treated as the Linux platform.
- Common typo variants such as `RHLE`, `redhat`, `cent os`, and `ubantu` are also recognized.
- Unknown OS text is no longer automatically classified as Linux during scan import.

# v1.0.3.42 - ai-ready-pale-gold-contrast / admin-topnav

Release date: 2026-05-29 09:10 +08:00

## Changes

- Added a distinct pale-gold visual style for `AI-ready` labels.
- Kept deep-gold frames for real AI judgement.
- Updated account inventory, AI provider, token cost, dashboard, reports, data quality, NMON, topology, and CMDB import labels to use `AI-ready` where AI is not actually executing yet.
- Added a compact System Admin top navigation bar that stays visible on SuperAdmin subpages such as health check, logs, jobs, token cost, and credentials.
- Collapsed long explanatory notes behind small help markers so operator screens use less vertical space.
- Kept System Admin navigation collapsed by default; categories expand as dropdowns instead of pushing the page down.

## Visual Rule

- Deep gold: actual AI judgement.
- Pale gold: AI-ready, can be routed to AI later.
- Gray: Script evidence.
- Green: CMDB / API / rule data.
- Amber: fallback.

# v1.0.3.35 - cmdb-import-fast-feedback

Release date: 2026-05-27 13:45 +08:00

## Changes

- CMDB import result pages no longer render the full raw error list in the top notice.
- Import results show elapsed seconds so operators know whether the request completed.
- UI import is capped at 2000 rows per file with a human-readable error and split-file suggestion.

## Why

Large CSV imports with many failed rows could make the browser appear stuck because the page rendered a very large raw Python error list before the readable summary table.

- Run targeted CSV/Excel import tests.
- Run full local test suite.
- Deploy to `192.168.1.221` first and verify `/health` reports `1.0.3.35`.
- Post a CSV with many bad rows and confirm the page returns a concise summary instead of a huge raw error blob.

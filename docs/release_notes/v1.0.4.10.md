# v1.0.4.10 - full-host-scope-opening-inspection

Build time: 2026-06-04 11:55 +08:00

## 變更內容

- 開門檢查改用後端全量主機範圍，不再被資產列表每頁 100 筆上限截斷。
- 巡檢摘要、NMON 狀態、NMON raw 主機對照、平台統計與 VMware 盤點同步改用全量主機查詢。
- CSV / Excel 匯出改為匯出完整篩選範圍，不再只輸出前 100 筆。
- 保留資產管理列表每頁 100 筆上限，避免日常頁面一次載入過多資料。

## 修正原因

現場診斷資料顯示資產主檔已有 592 筆正式資產，但開門檢查只列出 Linux 15、Windows 44、AS400 2、AIX 0。原因是後端部分服務使用 `list_hosts(page_size=10000)` 取全量資料，但 `list_hosts()` 為前台列表設計，會將每頁上限固定限制為 100，造成批次/統計功能只看見前 100 筆。

## 驗證重點

- 超過 100 台主機時，開門檢查候選數不再被截斷。
- 資產列表仍維持分頁，不會因修正而一次展開大量資料。
- CSV / Excel 匯出可輸出完整範圍。

# v1.0.3.40 - ai-judgement-visual-contrast

Release date: 2026-05-28 00:05 +08:00

## Changes

- Replaced flat judgement source badge rows with visual source cards on account inventory, AI provider, and token cost pages.
- AI judgement now uses a gold card and circular AI mark.
- Script evidence uses a neutral gray card.
- Data / rule evidence uses a green card.
- Fallback uses an amber card.
- Account inventory now shows the source path: Shell / Script evidence, CSV / Excel import data, PAM / owner rules, L3 AI judgement, and rule fallback.

## Why

Operators could see the labels, but the UI still looked like a single row of pills. This patch makes judgement source a real visual hierarchy so AI, Script, data rules, and fallback are distinguishable at a glance.

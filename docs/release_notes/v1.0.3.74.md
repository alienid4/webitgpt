# v1.0.3.74 asset-bulk-status-default-active-list

## 變更內容

- 資產列表新增「全選本頁」與「批次改狀態」工具列，可一次更新多筆資產生命週期。
- 下線、待刪除、汰除資產預設從資產管理清單隱藏，避免日常檢視被非運行資產干擾。
- 若要查看非運行資產，可勾選「顯示下線 / 待刪除」或直接用狀態篩選。
- 批次更新完成後會顯示成功筆數、略過筆數與目標狀態。

## 驗證

- `python -m compileall webapp`
- `python -m pytest tests/test_ui_contracts.py tests/test_asset_account_ui.py -q`
- `python -m pytest -q`

## 安裝

```bash
WEBITGPT_PIP_MODE=offline WEBITGPT_BUILD_TIME='2026-06-01 13:20:00 +08:00' bash install.sh
```

## 注意

- 本版不刪除資料，只調整資產狀態與預設清單篩選。
- 轉成下線、待刪除、汰除後，資料仍保留，可透過明確篩選找回。

# v1.0.3.78 cmdb-import-os-platform-auto-classify

Patch ID: `cmdb-import-os-platform-auto-classify`

## 變更內容

- CMDB CSV / Excel 匯入時，會先依 OS 版本與發行版文字自動推論平台分類。
- `CentOS`、`Red Hat`、`RHEL`、`RHLE`、`Ubuntu`、`Debian`、`Rocky` 等會直接歸類為 `linux`。
- 安裝 patch 時會自動修正既有 `end_device` 但 OS 明確可判斷的平台分類，並寫入稽核紀錄。

## 為什麼修

原始資料可能把 OS 版號寫得不完整或有手誤，但只要能看出是 Linux 發行版，就應先歸入 Linux 平台。正確版號可後續由掃描或人工驗證補齊，不應讓使用者逐筆手動分類。

## 驗證重點

- 匯入 `CentOS 7.6 1810`、`RHLE 8.10`、`Ubuntu 22.04` 後，平台分類應為 `linux`。
- 資料品質頁不應再把這類可推論項目留在高風險清單中。
- 既有資料安裝後會由 bootstrap 自動套用平台分類建議。

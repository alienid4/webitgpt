# v1.0.3.83 data-quality-lab-row-governance

## 變更內容

- 資料品質的 `cmdb_not_seen` 列會用目前 hosts 主檔 IP 反查資產，帶出 asset key，讓每筆資料可以直接進入資產編輯。
- 新增資料品質勾選批次動作：`勾選標為已汰除`。
- 停用、待汰除、已汰除資產不再納入資料品質檢查。

## 解決問題

- Lab 或測試主機若已混入 CMDB，會顯示為「CMDB 有但掃描未見」。現在可在資料品質頁勾選後標為已汰除，從品質檢查排除。
- 編輯資產後若狀態改為停用、待汰除或已汰除，資料品質不會再繼續顯示同一筆。

## 使用方式

1. 進入 `資料品質`。
2. 勾選確認為 Lab、測試、舊資料或不再納管的列。
3. 按 `勾選標為已汰除`。
4. 頁面會重新計算資料品質，該資產不再列入品質異常。

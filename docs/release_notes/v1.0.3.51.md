# v1.0.3.51 - CMDB Asset Pool Menu Entry

## 變更摘要

- 資產管理頁工具列新增 `CMDB 資產池` 分類入口。
- 可從工具列直接進入：
  - 全部資產池
  - 主機證據
  - 資料資產
  - 軟體 / AP
  - 人員窗口
  - 待分類
- `更多操作` 加入分類小標，將資料維護、匯出 / 匯入、治理工具分開。

## 驗證

- `python -m compileall webapp`
- `python -m pytest -q`
- 221 測試主機驗證 `/hosts` 可看到 `CMDB 資產池`、`人員窗口`、`軟體 / AP` 與 `待分類`。

## 使用方式

1. 開啟 `/hosts`。
2. 點工具列的 `CMDB 資產池`。
3. 依需求選擇 `人員窗口`、`軟體 / AP`、`資料資產` 或 `待分類`。
4. 進入分類後可檢視或編輯資產池項目。

## 注意事項

- 這版只改善入口與分類，不改匯入資料分流規則。
- 主機正式納管仍在資產管理主清冊與草稿流程處理。
- 人員、軟體、資料資產屬 CMDB 資產池，不會直接變成巡檢主機。

## Changes

- Added an admin action on `/reports/data-quality` to apply platform classification suggestions.
- Hosts whose OS text clearly indicates Linux, Windows, AIX, AS400, or VMware can be corrected from `end_device` or another mismatched type.
- Updates are audited and mark `host_type_source=os_inference_rule`.
- Dashboard platform counts and inspection platform filters use the corrected `host_type` after applying suggestions.

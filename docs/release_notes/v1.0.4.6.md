# v1.0.4.6 - cmdb-relationship-compact-search-results

Build time: 2026-06-03 23:20 +08:00

## 變更重點

- CMDB 系統關聯覆蓋明細預設收合，只保留搜尋列與狀態提示。
- 輸入系統或資產名稱後才展開符合的系統列，減少預設畫面高度。
- 新增「顯示全部」按鈕，需要完整盤點時才展開全部系統。
- 補 UI contract test，避免後續版本又回到預設攤開大表格。

## 使用方式

1. 進入「資產管理」。
2. 點選「CMDB 關聯總覽」。
3. 在「系統關聯覆蓋明細」輸入系統或資產名稱。
4. 系統會顯示符合筆數並展開符合清單。
5. 若需完整檢視全部系統，按「顯示全部」。

## 安裝方式

```bash
tar -xzf webitgpt_v1.0.4.6-patch-cmdb-relationship-compact-search-results_<timestamp>.tar.gz
cd webitgpt_v1.0.4.6-patch-cmdb-relationship-compact-search-results_<timestamp>
sudo bash install.sh /opt/webitgpt
```

## 驗證方式

```bash
curl -fsS http://127.0.0.1:8002/health
curl -fsS http://127.0.0.1:8002/hosts/cmdb-relationships >/tmp/webitgpt_cmdb_relationships.html
```

確認頁面含有 `cmdbSystemFilter`、`cmdbSystemResults` 與 `cmdbSystemShowAll`。

# v1.0.3.94 - release-installer-sh-wrapper

## 變更內容

- Release patch 套件結構維持 v1.0.3.89 標準：

```text
webitgpt_v1.0.3.94-patch-release-installer-sh-wrapper_<yyyymmddHHMM>/
  copy_commands.md
  install.sh
  PACKAGE_MANIFEST.txt
  payload/
  RELEASE_NOTE.md
  ROLLBACK.sh
```

- `install.sh` 與 `ROLLBACK.sh` 增加 shell wrapper。
- 即使外層腳本用 `sh install.sh` 呼叫，也會自動切回 bash 後再啟用 `pipefail`。

## 為什麼修正

v1.0.3.93 的套件結構已恢復與 v1.0.3.89 一致，但 `install.sh` 內的 `set -euo pipefail` 仍需要 bash。若現場外層腳本使用 `sh install.sh`，會出現 `invalid option name: pipefail`。

本版保留 89 版 tar 結構，同時讓 installer 能相容 `sh` 外層呼叫。

## 安裝

```bash
tar -xzf webitgpt_v1.0.3.94-patch-release-installer-sh-wrapper_<yyyymmddHHMM>.tar.gz
cd webitgpt_v1.0.3.94-patch-release-installer-sh-wrapper_<yyyymmddHHMM>
sudo bash install.sh /opt/webitgpt
```

若既有外層 shell 使用 `sh install.sh`，本版也可相容。

## 驗證

- `python -m pytest tests/test_ui_contracts.py -q`
- `python -m pytest tests/test_asset_account_ui.py -q`
- `python -m pytest -q`
- 在 Linux 上以 `sh install.sh /not_exist_path` 驗證不會在 `pipefail` 失敗。

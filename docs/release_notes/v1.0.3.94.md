# v1.0.3.94 - release-installer-sh-wrapper

## 變更內容

- Release patch TAR 維持 v1.0.3.89 相容版型：

```text
webitgpt_v1.0.3.94-patch-release-installer-sh-wrapper_<yyyymmddHHMM>/
  copy_commands.md
  install.sh
  PACKAGE_MANIFEST.txt
  payload/
  RELEASE_NOTE.md
  ROLLBACK.sh
```

- `install.sh` 與 `ROLLBACK.sh` 加入 `sh install.sh` 相容前置處理。
- 若現場外層腳本用 `sh install.sh` 呼叫，installer 會自動切回 bash，再啟用 `pipefail`。
- 修正 Windows 端打包造成的 CRLF 風險；Release TAR 內的 shell scripts 固定使用 Linux LF。

## 修正原因

v1.0.3.93 已恢復 v1.0.3.89 的資料夾式 TAR 結構，但現場外層腳本可能用 `sh install.sh` 呼叫，導致 `pipefail` 在 POSIX sh 內失敗。

v1.0.3.94 保留 3.89 的 TAR 結構，只修 installer 相容性與 shell script 換行格式，避免破壞既有現場腳本。

## 安裝方式

```bash
tar -xzf webitgpt_v1.0.3.94-patch-release-installer-sh-wrapper_<yyyymmddHHMM>.tar.gz
cd webitgpt_v1.0.3.94-patch-release-installer-sh-wrapper_<yyyymmddHHMM>
sudo bash install.sh /opt/webitgpt
```

若既有現場腳本呼叫 `sh install.sh`，本版也會自動轉交 bash 執行。

# v1.0.3.41 - static-asset-cache-busting

Release date: 2026-05-28 00:15 +08:00

## Changes

- Added a version query parameter to the main CSS and JavaScript assets.
- The query value is based on `VERSION` and `PATCH_ID`, so each patch forces the browser to load the latest UI files.
- Updated page-level scripts for account inventory, hosts, host import, NMON, inspections, housekeeping, backup, patches, and SSH key pages.

## Why

v1.0.3.40 changed the UI, but browsers may keep using the old cached `cathay.css`. That makes the system look unchanged even when the backend and templates are already patched. This release removes that ambiguity.

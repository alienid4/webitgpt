# v1.0.3.33 - cmdb-real-fields-scan-visibility

Release time: 2026-05-27 10:45 +08:00

## Changes

- CMDB CSV import now accepts the real Chinese field names from the source workbook, including asset sequence, APID, host name, IP, backup frequency, data retention, backup method, CIA values, and request number.
- Network scan reports now show the actual discovered count, CMDB-managed count, unmanaged draft candidates, and visible row count so operators can see why a `/24` scan is not just one host.
- TCP discovery ports now include common AD, SMB, FTP, RDP, webitgpt 8002, app 5000, and 50000-series service ports seen in the field.

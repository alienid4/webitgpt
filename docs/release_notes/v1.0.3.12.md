# v1.0.3.12 - AP account import
Build time: 2026-05-26 17:30:00 +08:00
Patch ID: ap-account-import

## Changes

- Added AP account CSV / Excel import support.
- Required fields are `app_id`, `system_name`, and `account`.
- Optional fields such as `owner`, `pam_managed`, `privilege`, `last_login`, and `remark` may be blank.
- Missing owner and admin accounts without PAM are marked for review instead of blocking import.

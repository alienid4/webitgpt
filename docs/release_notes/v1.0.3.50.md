# v1.0.3.50 - CMDB Asset Pool Tabs Edit

## 變更摘要

- CMDB 資產池新增分類檢視：
  - 全部
  - 主機證據
  - 資料資產
  - 軟體 / AP
  - 人員窗口
  - 待分類
- 資產池每列新增「編輯」。
- 人員、軟體、資料資產可直接修正整理後欄位。
- 編輯時保留原始 Excel `raw`，避免失去來源證據。
- 編輯需填寫變更原因，系統會記錄 `updated_by`、`updated_at` 與 edit history。

## 驗證

- `python -m compileall webapp`
- `python -m pytest -q`

## 使用方式

1. 開啟 `/cmdb/workbook`。
2. 在 CMDB 資產池區切換分類。
3. 選擇 `人員窗口` 或 `軟體 / AP`。
4. 點列上的「編輯」。
5. 修正整理後欄位並填寫變更原因。
6. 儲存後回分類清單檢查。

## 注意事項

- 編輯不會修改原始 Excel `raw`。
- 正式主機欄位仍建議到資產管理主機頁編輯。
- 這版讓資產池變成整理區，不是正式 CMDB 的強制晉升流程。

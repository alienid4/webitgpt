# v1.0.3.58 - Offline Pip Patch Install

## Summary

This patch fixes patch installation on isolated hosts. The installer no longer tries to reach the public Python package index by default, so offline servers do not hang on pip retry messages.

## Changes

- `scripts/install.sh` now defaults to `WEBITGPT_PIP_MODE=offline`.
- Offline mode uses a bundled `wheelhouse` when present.
- If no `wheelhouse` is present, offline mode runs pip with `--no-index` so it only validates the existing virtual environment.
- `WEBITGPT_PIP_MODE=skip` can be used when dependencies are already prepared and pip should be skipped entirely.
- `WEBITGPT_PIP_MODE=online` remains available for connected lab/dev hosts.

## Field Guidance

If the install is currently retrying `/simple/pip/`, stop it and install this patch. For an already prepared host, the safe command is:

```bash
WEBITGPT_PIP_MODE=offline WEBITGPT_BUILD_TIME='2026-05-31 11:55:00 +08:00' bash install.sh
```

If the venv is known to be complete:

```bash
WEBITGPT_PIP_MODE=skip WEBITGPT_BUILD_TIME='2026-05-31 11:55:00 +08:00' bash install.sh
```

# v1.0.3.66 - Topology Unassigned Core Label

## Purpose

Fix a topology UI issue where systems without an explicit core assignment were shown under the default core label. This could make unrelated systems appear to belong to the wrong core.

## What Changed

- Systems without explicit core metadata no longer fall back to the first core.
- Unassigned systems now appear under `未歸屬核心`.
- The core impact first column label is changed from `六大核心` to `核心歸屬`.
- Topology selectors now display asset/system names first and hide internal `SYS-*` ids from the visible option text.
- Internal ids remain searchable and continue to be used as stable keys.

## Field Expectation

When selecting a system that has no explicit core assignment:

- first column should highlight `未歸屬核心`
- it should not highlight `好麥證券`
- dropdown should show the human asset/system name, not the internal `SYS-*` id

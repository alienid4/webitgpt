# v1.0.3.53 - CMDB Direct Governed Import

## 變更摘要

- CMDB Excel 匯入主流程改為直接 `整份治理匯入`。
- `預檢` 改名為 `只預檢，不寫入`，並移到 `進階匯入動作`。
- 移除 `1. 預檢整份 Excel` / `2. 整份治理匯入` 的步驟感，避免現場以為必須先預檢。

## 操作方式

1. 開啟 `/cmdb/workbook`。
2. 選擇 Excel 檔。
3. 直接按 `整份治理匯入`。
4. 匯入完成後，到 `CMDB 資產池` 查看資料、軟體 / AP、人員窗口與待分類。

## 補充

- `只預檢，不寫入` 仍保留，放在 `進階匯入動作`。
- 預檢適合要先看 sheet 被分到哪一類的人使用；一般現場匯入可直接治理匯入。

## 驗證

- `python -m compileall webapp`
- `python -m pytest -q`
- 221 測試主機驗證 `/cmdb/workbook` 顯示主按鈕 `整份治理匯入`，且預檢只在進階區。

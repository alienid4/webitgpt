# v1.0.3.34 - cmdb-import-report-excel-drafts

Release date: 2026-05-27 11:45 +08:00

## Changes

- CMDB import results now show total rows, successful rows, created rows, updated rows, draft rows, failed rows, error categories, and human-readable suggestions.
- Asset import supports `.xlsx` in the same upload entry as CSV, and the API exposes Excel import, export, validate, and validation-error download endpoints.
- CSV template/export/error downloads now include UTF-8 BOM to reduce Excel garbling on Traditional Chinese Windows desktops.
- Draft assets can be bulk promoted to active or bulk updated for common fields after nmap/IPAM creates draft rows.

## Validation Plan

- Run targeted unit/contract tests for CSV/Excel import and asset draft UI contracts.
- Deploy to `192.168.1.221` first and verify `/health` reports `1.0.3.34`.
- Verify the CMDB asset page exposes CSV export, Excel export, and draft bulk actions.

## Field Notes

- For large CSV imports, use the import page first; the result panel tells operators how many rows entered CMDB, how many became drafts, and why failed rows failed.
- For Excel files, save as `.xlsx`; legacy `.xls` is not supported by this patch.
- Draft rows from scanning should be reviewed, bulk-filled when needed, then bulk-promoted to active.

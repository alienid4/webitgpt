# v1.0.4.9 - data-quality-detail-on-demand-results

## Purpose

This patch makes the data quality workbench more compact. CMDB detail rows are now shown only after the operator searches or explicitly clicks show all.

## Changes

- Data quality CMDB detail table is hidden by default.
- Added a compact search box for issue type, asset name, host, IP, status, and suggested action.
- Added a show-all button for operators who need the full detail list.
- Kept bulk action controls available while avoiding a large default table.
- Added UI contract checks to ensure detail-row markers stay on body rows, not table headers.

## Install

```bash
tar -xzf webitgpt_v1.0.4.9-patch-data-quality-detail-on-demand-results_<timestamp>.tar.gz
cd webitgpt_v1.0.4.9-patch-data-quality-detail-on-demand-results_<timestamp>
sudo bash install.sh /opt/webitgpt
```

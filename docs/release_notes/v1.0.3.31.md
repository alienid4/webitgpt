# v1.0.3.31 - api-key-post-install-verify

Release time: 2026-05-26 23:45 +08:00

## Changes

- Added `/api/v1/post-install/verify` for API key gated post-install verification.
- The endpoint requires a Bearer token with `system:read` scope.
- `scripts/post_install_verify.sh` now supports `API_TOKEN=wgpt_xxx` to verify through the protected API path.
- The post-install UI shows both script-only and API key verification commands.

## Verification

- Missing token returns 401.
- Valid `system:read` token returns JSON with `ok`, version, patch id, and check details.
- Run `python -m pytest -q`.

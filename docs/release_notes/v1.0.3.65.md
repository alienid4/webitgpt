# v1.0.3.65 - Topology Full Asset Master Scan

## Purpose

Fix two field workflow gaps:

- Core impact topology could still show fewer hosts than the asset master when the host collection was larger than one asset-list page.
- After bulk draft promotion, operators could not clearly tell whether records became formal assets or were skipped.

## What Changed

- Topology host backfill now reads the full host collection directly, not the paginated asset-list helper.
- Selected business systems can show all matching asset-master hosts in the third topology column.
- Draft promotion results now show:
  - promoted count
  - remaining draft count
  - top skipped reasons
  - links to formal assets and remaining drafts

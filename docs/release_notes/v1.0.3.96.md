# v1.0.3.96 - asset-pool-kpi-auto-ingest

## Summary

資產管理 KPI 改成「資產池治理」口徑：匯入資料會先全部自動納入資產池，只有草稿、缺關鍵欄位或衝突資料才列為人工待判斷。

## Changes

- 將資產管理摘要卡改為「已納入資產池、可自動彙整、人工待判斷、需補關鍵資料、環境種類、平台種類」。
- 增加短說明，避免使用者把完整度、環境種類、平台種類誤認為要與資產總數相加。
- 摘要計算改用目前篩選條件的全量資料，不再只計算本頁清單。
- 人工待判斷改為例外集合，草稿與缺關鍵資料都會納入。

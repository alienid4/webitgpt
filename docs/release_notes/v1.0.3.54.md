# v1.0.3.54 - Cumulative CMDB 3.44 to 3.53 Patch

## 目的

本版修正現場可能出現的「版號同為 v1.0.3.53，但功能不同」問題。

原因是 v1.0.3.53 原本是增量 patch，只包含當版直接治理匯入的變更；如果現場不是從 v1.0.3.52 逐版升級，而是從較舊底版直接套用 v1.0.3.53，就可能漏掉 v1.0.3.51 的 `CMDB 資產池` 工具列入口與相關檔案。

## 變更內容

- 改用累積修補包，補齊 v1.0.3.44 到 v1.0.3.53 的可部署檔案。
- 補齊資產管理工具列的 `CMDB 資產池` 入口。
- 補齊 CMDB 資產池分類、編輯、空狀態診斷與整份治理匯入。
- 補齊主機資料目錄權限防護，避免資料目錄權限異常時直接噴 500。
- 補齊主機新增與編輯的錯誤防護，讓現場看得到可處理原因。

## 驗證方式

- `python -m compileall webapp`
- `python -m pytest -q`
- 221 測試主機確認 `/health` 回報 v1.0.3.54。
- 221 測試主機確認 `/hosts` 顯示 `CMDB 資產池`。
- 221 測試主機確認 `/cmdb/workbook` 顯示 `整份治理匯入`。

## 現場建議

若現場主機不是逐版從 v1.0.3.44 升級到 v1.0.3.53，請直接套用本版或更新的累積 patch。這樣可以避免只看版號相同，但 UI 或服務檔其實缺檔。

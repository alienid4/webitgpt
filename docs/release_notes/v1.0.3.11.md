# v1.0.3.11 - RHEL 9.6 目標離線包標記

Build time: 2026-05-26 16:55:00 +08:00
Patch ID: rhel96-offline-target-package

## 變更內容

- 完整離線包支援 `TARGET_OS_LABEL`，包名、`README_INSTALL.txt` 與 prerequisite `manifest.txt` 會標示目標 OS。
- RHEL 9.6 新機移植可產生清楚標記的 target package，避免與 Rocky/RHEL 9.7 包混淆。
- release note 明確記錄 build OS 與 target OS，方便稽核與安裝前確認。

## RHEL 9.6 產包指令

在可上網的 Rocky/RHEL 9 build host 執行：

```bash
cd /opt/webitgpt

TARGET_OS_LABEL="RHEL 9.6" \
MONGO_IMAGE=docker.io/library/mongo:7.0 \
INCLUDE_MONGO_IMAGE=1 \
INCLUDE_NMON=1 \
bash scripts/prepare_221_full_offline_bundle.sh
```

## 安裝方式

```bash
tar -xzf webitgpt_full_offline_1.0.3.11-rhel96-offline-target-package_rhel-9-6_*.tar.gz
cd webitgpt_full_offline_1.0.3.11-rhel96-offline-target-package_rhel-9-6_*
sudo bash INSTALL_ALL.sh
curl http://localhost:8002/health
curl http://localhost:8002/ready
```

## 注意

- 221 目前是 Rocky Linux 9.7；若正式環境要求 RPM 完全依 RHEL 9.6 repo 產出，請在 RHEL 9.6 或可用 RHEL 9.6 repo 的 build host 重建完整離線包。
- 套件仍不得包含 `data/`、`logs/`、`backup/`、`venv/`、`.git/`、Mongo dump、密碼、token 或 private key。

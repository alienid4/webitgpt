# v1.0.4.7 - asset-list-on-demand-results

Build time: 2026-06-04 06:45 +08:00

## 變更摘要

- 資產管理頁的資產明細預設收合，只保留一行精簡入口。
- 搜尋、篩選、點擊「已納入資產池」或按「顯示全部」後才展開資產清單。
- 平台分類與環境分類維持點擊數字卡後才顯示，避免主畫面被明細表格佔滿。
- 與 CMDB 系統關聯覆蓋明細採用一致的按需顯示規則。

## 使用方式

1. 進入資產管理頁，預設只看摘要、篩選列與精簡的資產明細入口。
2. 需要找特定資產時，在搜尋或篩選條件輸入後按「篩選」。
3. 需要查看完整清單時，按「顯示全部」。
4. 需要看平台或環境分布時，點擊上方的「平台種類」或「環境種類」數字卡。

## 安裝方式

```bash
tar -xzf webitgpt_v1.0.4.7-patch-asset-list-on-demand-results_<timestamp>.tar.gz
cd webitgpt_v1.0.4.7-patch-asset-list-on-demand-results_<timestamp>
sudo bash install.sh /opt/webitgpt
```

## 驗證方式

```bash
curl -fsS http://127.0.0.1:8002/health
curl -fsS http://127.0.0.1:8002/hosts >/tmp/webitgpt_hosts.html
curl -fsS "http://127.0.0.1:8002/hosts?show_assets=1" >/tmp/webitgpt_hosts_all.html
```

預期 `/hosts` 預設包含 `asset-list-gate`，`/hosts?show_assets=1` 才包含完整資產表格。

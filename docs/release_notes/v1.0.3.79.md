## 變更重點

- CMDB CSV / Excel 匯入時依平台分類自動帶入預設連線方式。
- 預設規則：
  - `linux` -> `ssh`
  - `windows` -> `winrm`
  - `aix` -> `ssh_raw`
- 安裝 patch 時會自動補齊既有資料缺少的連線方式。
- 自動補齊來源標記為 `connection_source=platform_default_rule`，日後仍可由人工或 PAM/憑證治理流程覆蓋。

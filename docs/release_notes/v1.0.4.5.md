# v1.0.4.5 - cmdb-relationship-searchable-system-filter

## Changes

- Added a searchable system filter to the CMDB relationship coverage detail table.
- Changed the selected-system control from a long plain select list to a searchable datalist input.
- Relationship coverage now prefers friendly system or asset labels before showing APID-style codes.
- APID, hostname, asset sequence, IP, platform, group, and owner values remain searchable helper terms.
- Added regression coverage so imported records with a real system label in `device_type` do not fall back to `N-xxx` as the main display.

## Field Note

This patch changes display, filtering, and grouping behavior only. It does not delete, import, or mutate CMDB asset rows.

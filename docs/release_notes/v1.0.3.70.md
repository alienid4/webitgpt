# v1.0.3.70 - second-layer-relation-matrix-import-edit

Release date: 2026-06-01 11:25 +08:00

## 重點

- 新增第二層系統關聯 Excel 匯入，可吃「來源系統列、目標系統欄、格子標記關聯」的矩陣格式。
- 匯入只建立第二層系統與系統間關聯，不設定第一層核心歸屬。
- 系統拓撲的手動關聯管理新增可展開編輯，可調整來源、目標、類型、Port、服務與備註。
- 匯入流程不保存原始 Excel，稽核只記錄狀態、格式與數量。

## 驗證

- `python scripts/import_system_relations.py <local-sensitive-xlsx> --dry-run`
- `python -m pytest tests/test_ui_contracts.py::test_dependency_mapping_and_reconcile_contracts_exist tests/test_asset_account_ui.py::test_global_judgement_source_visibility_contracts_exist -q`
- `python -m compileall webapp`
- `python -m pytest -q`

## 操作提醒

- 第一層核心歸屬仍請到「系統管理 > 規則與治理 > 核心歸屬管理」設定。
- 第二層關聯匯入後，可在「系統拓撲 > 手動關聯管理」逐筆展開編輯。
- 敏感 Excel 請放在本機或受控主機，不要提交到 GitHub。

# v1.0.3.67 - CMDB Relationship Topology Center

## Purpose

Fix the CMDB relationship overview action that opens the core impact topology. The button now resolves the selected CMDB system to the actual topology system center before navigation.

## What Changed

- `開核心影響圖`, `看這套系統影響圖`, and row-level `看影響圖` now use `topology_center`.
- CMDB relationship rows match topology systems by system id, display name, and host references.
- If no topology system can be matched, the link falls back to the human display name instead of a low-level CMDB grouping key.

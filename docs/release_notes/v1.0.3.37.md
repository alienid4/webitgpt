# v1.0.3.37 - ai-judgement-gold-frame-ui

Release date: 2026-05-27 23:20 +08:00

## Changes

- Added a visible gold AI judgement card to the post-install verification page.
- Added gold AI-ready framing to the L3 deep check panel.
- Added reusable source badges for `AI 判斷`, `AI + Script`, and `Script 接手`.
- L3 now visibly communicates: Shell collects evidence, AI interprets, Script takes over when AI is unavailable.

## Why

v1.0.3.36 defined the design rule in documents and slides, but the operational UI did not yet show the gold AI frame. This patch makes the judgement source visible in the actual webitgpt pages.

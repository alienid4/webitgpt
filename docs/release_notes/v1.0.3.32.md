# v1.0.3.32 - api-key-verify-visibility

Release time: 2026-05-27 00:15 +08:00

## Changes

- Added visual mode cards to the post-install page so users can distinguish API Key verification from script-only checks.
- Displayed the required `system:read` scope, the protected API path, the `verification_source=api_key` response marker, and copyable curl examples.
- Added `verification_source`, `verification_label`, and `required_scope` to `/api/v1/post-install/verify`.
- Added a RHEL 9.6 installer patch that auto-installs native podman/container runtime packages when available from target repositories.
- Changed the prerequisite installer to stop before app bootstrap if local MongoDB is still unreachable, avoiding a long bootstrap traceback.

## Verification

- Run `python -m pytest -q`.
- Open `/reports/post-install` and confirm the API Key and Script mode cards are visible.
- Call `/api/v1/post-install/verify` with a `system:read` token and confirm `verification_source` is `api_key`.
- Run `bash -n` on the patched RHEL 9.6 prerequisite and patch installer scripts.
- Apply the patch to an extracted full offline package and confirm the bundled prerequisite archive and `INSTALL_ALL.sh` are updated.

# v1.0.3.1 - 效能月報主管摘要與技術明細

Build time: 2026-05-25 00:30:00 +08:00
Patch ID: nmon-executive-technical-views

## 變更內容

- 效能月報新增兩個視角：
  - `主管摘要`：預設頁面，只保留決策用數字、風險清單、影響說明、可選作法與趨勢圖。
  - `技術明細`：保留 NMON raw file pipeline、IBM NMON 採樣口徑、CSV/JSON、部署計畫、立即採樣、採樣明細與主機 NMON 狀態。
- 主管摘要移除第一屏的 raw file、pipeline、JSON/API、nmon 指令參數等工程細節。
- 主管摘要新增「本月結論」、「主管只看四個數字」、「可選作法」區塊，讓非技術主管也能判斷是否需要決策。
- 技術明細保留原本維運所需證據，方便工程師追查資料來源與採樣品質。
- 修正 `/nmon` 支援 `view=executive|technical`，預設為主管摘要。

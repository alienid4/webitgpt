# v1.0.3.71 - relation-import-search-ux

## 重點

- 系統拓撲第一屏新增「匯入第二層關聯表」入口，匯入功能不用再到手動關聯區尋找。
- 第二層關聯 Excel 支援「預檢數量」與「正式匯入」兩種動作。
- 匯入後顯示格式、來源列、系統數與關聯數，並提供查看關聯、開啟影響圖與回 CMDB 總覽的下一步。
- 手動關聯管理新增「關聯表搜尋」，可查來源、目標、APID/代號、Port、服務與備註。
- 關聯清單改為先顯示系統名稱，再保留系統 ID，降低 SYS 代號判讀成本。

## 驗證

- `python -m compileall webapp`
- `python -m pytest -q`
- 221 測試主機部署後檢查 `/health` 與 `/dependencies?view=radial&relation_q=test`

## 注意

- 第一層核心歸屬仍需由核心歸屬管理維護；本版只處理第二層系統對系統關聯。
- 現場 Linux 內網主機請使用離線安裝模式：`WEBITGPT_PIP_MODE=offline bash install.sh`

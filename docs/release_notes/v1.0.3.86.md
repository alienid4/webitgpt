# v1.0.3.86 opening-check-readiness-workflow

## 變更摘要

- 今日巡檢新增「系統巡檢分組」，可直接看到每個系統的主機數、已巡檢、可巡檢與待補條件。
- 「開始巡檢目前範圍」一次最多處理 500 台，避免匯入百台以上時只跑到部分主機。
- 今日巡檢卡片會讀取 `inspection_results`，按下巡檢後畫面能反映 L1 開門檢查結果。
- SSH / AIX SSH Raw / Ansible / NMON 預設改用系統管理設定的 L1 採集帳號。

## 驗證重點

- 匯入完成後先進「今日巡檢」，從「系統巡檢分組」選系統。
- 若顯示「可巡檢」，可按「巡檢目前範圍」。
- 若顯示「待補條件」，先補 IP、轉正式、平台分類或採集協定。

## 安裝

```bash
WEBITGPT_PIP_MODE=offline bash install.sh
```

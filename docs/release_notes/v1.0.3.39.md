# v1.0.3.39 - ai-key-budget-tier-routing

Release date: 2026-05-27 23:55 +08:00

## Changes

- Added L1 / L2 / L3 API key tier settings to the AI provider page.
- Added model, monthly budget, per-tier budget, max check level, and fallback strategy fields.
- Added a budget routing preview API so admins can see which key tier would be selected.
- Added budget policy status to the Token Cost page.

## Operating Rule

API Keys are not required to install this patch. Real keys must be entered only in the backend SuperAdmin page and must not be pasted into chat, docs, Git, screenshots, or the frontend.

Recommended routing:

- L1: Script first, no AI by default.
- L2: Low-cost API key for summaries and simple classification.
- L3: Higher-cost API key for deep judgement over CMDB, NMON, accounts, logs, and topology.
- Over budget: downgrade tier or use Script fallback.

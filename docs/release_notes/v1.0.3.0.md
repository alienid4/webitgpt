# v1.0.3.0 - NMON 效能月報與系統拓撲修正

Build time: 2026-05-24 23:33:13 +08:00
Patch ID: nmon-monthly-topology-autodev

## 變更內容

- 完成 NMON 效能月報頁面整理，補上 raw file pipeline、IBM NMON 採樣口徑、日報/週報/月報、架構部數據摘要、風險追蹤清單、主機效能排名、採樣明細與趨勢區塊。
- 修正 NMON raw file 上傳提示文字，避免出現亂碼或難以理解的訊息。
- 修正系統拓撲全螢幕按鈕，優先使用頁內全螢幕 overlay，避免按鈕看起來失效。
- 修正系統拓撲 API 的未納管節點參數，讓畫面勾選與 API 結果一致。
- 強化拓撲焦點顯示，非相關節點與線條會更明顯淡化，方便閱讀。
- 更新版本資訊，讓頁首與 health/version 顯示可追蹤到本次修補。
- 強化 patch 打包排除規則，不包含 runtime 資料、log、debug report、venv、backup、.git 或 Mongo dump。

## 已知限制

- NMON 月報仍需要正式 NMON raw file 或既有採樣資料；沒有 raw data 時只會顯示空報表與安裝/採樣狀態。
- 系統拓撲仍以 CMDB 關聯資料與 ss/nmap 採集結果為主；若 CMDB 未填或未採集，圖上不會憑空產生正式關聯。

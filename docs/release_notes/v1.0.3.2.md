# v1.0.3.2 - 效能月報技術趨勢圖

## 變更

- 效能月報技術明細新增 `CPU / RAM / Disk 趨勢圖`。
- 趨勢圖用同一份 NMON report data model，依目前篩選條件顯示 CPU、RAM、Disk 三條平均線。
- 技術頁保留趨勢表格，方便維運人員看到每個時間點的數字與樣本數。
- 主管頁維持摘要圖與風險清單，不顯示 NMON raw pipeline 或技術趨勢明細。

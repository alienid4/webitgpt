# webitgpt v1.0.2.97 Release Note

建立時間：2026-05-22 08:35 +08:00

## 版本定位

本版重點是把目前開發成果整理成可移植版本，並補齊新主機離線安裝、AI 工具會議架構圖、Debug Bundle、NMON 月報與管理後台相關文件。

## 主要變更

- 補齊完整離線安裝流程：221 產完整離線包，224 離線主機只執行 `INSTALL_ALL.sh`。
- 離線包排除 runtime/test 資料：不包含 `data/`、`logs/`、`backup/`、`venv/`、`.git/`、Mongo dump。
- 離線包包含必要軟體：RPM、Python wheels、MongoDB container image、nmap、nmon、podman。
- 補強開發後台與 Debug Bundle / AI Debug Loop 文件與流程。
- 補強 NMON raw file pipeline、效能月報與 IBM NMON 採樣口徑說明。
- 補強資產管理、帳號盤點、開門檢查、深度檢查、系統拓撲、Housekeeping 等功能文件與 UI。
- 新增 `docs/mockups/webitgpt_architecture_diagrams.html`，提供多種架構圖 Tab，可截圖放入 AI 工具討論會資料。

## 完整離線包

221 產包位置：

```bash
/opt/webitgpt/dist/webitgpt_full_offline_1.0.2.97-full-system-validation-artifacts_*.tar.gz
```

224 離線安裝方式：

```bash
tar -xzf webitgpt_full_offline_1.0.2.97-full-system-validation-artifacts_*.tar.gz
cd webitgpt_full_offline_1.0.2.97-full-system-validation-artifacts_*
sudo bash INSTALL_ALL.sh
curl http://localhost:8002/health
curl http://localhost:8002/ready
systemctl status webitgpt --no-pager
```

## 驗證

- 版本格式符合 `v1.0.X.Y`，且每段數字未超過 99。
- 完整離線包需驗證 SHA256。
- 完整離線包需確認包含 RPM、wheelhouse、Mongo image 與 `INSTALL_ALL.sh`。
- 完整離線包需確認未包含 runtime/test 資料。

## 已知風險

- 224 目前尚未完成 SSH key 部署，無法遠端自動安裝。
- RHEL 9.6 大方向可用，但若 RPM 相依版本與 221 Rocky 9.7 有差異，正式環境建議使用同版 RHEL 9.6 可上網主機重建完整離線包。

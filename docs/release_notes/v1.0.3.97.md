# v1.0.3.97 - asset-pool-kpi-clickable-governance

## 變更重點

- 修正資產管理 KPI 口徑：可自動彙整 = 已納入資產池 - 人工待判斷。
- 點選「可自動彙整」、「人工待判斷」、「需補關鍵資料」會直接套用對應清單篩選。
- 新增 `governance=auto/review/missing` 後端篩選條件，避免 KPI 與明細清單口徑不同。

## 使用說明

- `已納入資產池`：目前篩選條件下的資產總數。
- `可自動彙整`：可直接納入日常查詢、巡檢準備與彙整的資產。
- `人工待判斷`：草稿、缺關鍵欄位或其他需人確認的資產。
- `需補關鍵資料`：缺少必填治理欄位的資產。

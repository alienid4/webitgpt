# v1.0.4.4 - cmdb-relationship-system-auto-classify

## Changes

- Adjusted CMDB relationship coverage grouping to use only trusted system keys.
- Explicit `system_name` still has highest priority.
- `asset_name` is used only when it does not look like a generic device type, group name, host platform, or placeholder.
- `APID` remains a fallback when no reliable system name is available.
- Generic or ambiguous assets are grouped as `待補系統關聯` instead of being counted as real systems.

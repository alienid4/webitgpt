## 變更內容

- 新增完整離線包非互動安裝模式。
- `INSTALL.sh` 支援 `WEBITGPT_NONINTERACTIVE=1`。
- 自動安裝時可由 `WEBITGPT_SUPERADMIN_PASSWORD` 提供初始最高管理員密碼，避免 SSH/批次部署卡在密碼輸入。
- 若非互動安裝沒有提供密碼，會清楚失敗並提示需要設定環境變數，不再高 CPU 空轉。
- 保留原本人工互動安裝模式，工讀生仍可照提示逐步輸入。

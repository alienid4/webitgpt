# v1.0.3.93 - release-tar-89-compatible-layout

## 變更內容

- Release patch tar 結構恢復與 v1.0.3.89 相同。
- 解開 tar 後會得到版本資料夾，例如：

```text
webitgpt_v1.0.3.93-patch-release-tar-89-compatible-layout_<yyyymmddHHMM>/
  copy_commands.md
  install.sh
  PACKAGE_MANIFEST.txt
  payload/
  RELEASE_NOTE.md
  ROLLBACK.sh
```

- 現場 shell 可沿用既有流程：

```bash
tar -xzf webitgpt_v1.0.3.93-patch-release-tar-89-compatible-layout_<yyyymmddHHMM>.tar.gz
cd webitgpt_v1.0.3.93-patch-release-tar-89-compatible-layout_<yyyymmddHHMM>
sudo bash install.sh /opt/webitgpt
```

## 為什麼修正

v1.0.3.92 把 `install.sh` 放在 tar 解開後的第一層，雖然安裝入口清楚，但與 v1.0.3.89 的套件資料夾結構不同，會影響已經寫好的現場 shell。

本版修正為以 v1.0.3.89 為標準，維持現場腳本相容性。

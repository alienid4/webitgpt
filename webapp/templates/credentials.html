Client 端前置作業

  1. 在被管主機、AD、PAM 或跳板機建立正式帳號；`itwebL1`、`itwebL2`、`itwebL3` 只是預設範例。
  2. 若帳號不存在，可下載 Linux 偵測/建立腳本；腳本會先偵測帳號，存在就跳過，不存在才建立。
  3. 暫時密碼依目前規範使用 `1qaz@WSX`；日後交由 PAM 納管後請立即輪替。
  4. L1 不給 sudo；L2 建立 sudo 權限；L3 建立 sudo 權限但應搭配 PAM、審核與時間限制。
  5. 完成後再用這裡的帳號名稱對應掃描、盤點與深度檢查流程。

腳本會做什麼

展開查看偵測與建立規則。
  • 使用 `id 帳號` 偵測 `itwebL1 / itwebL2 / itwebL3` 是否存在。
  • 不存在時執行 `useradd -m -s /bin/bash` 並設定暫時密碼。
  • 建立 `/etc/sudoers.d/webitgpt-collection`，給 L2 / L3 sudo 權限。
  • 使用 `visudo -cf` 驗證 sudoers 檔案。
